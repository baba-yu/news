ユーザーの継続予測に照らすと、「悪意ある局所 LLM とゼロトラスト」の主軸は本当に二分された一日を迎え、その分かれ方は、まぎれのない裏づけよりも多くを教える。Mindgard の未修正の Cursor の欠陥は、この仮説が挙げる汚染された成果物の形そのものだ — リポジトリの直下に仕込まれた git.exe が、フォルダを開いた瞬間に利用者の権限で実行される。ただしそれは、モデルのレジストリではなくリポジトリを通って届いた。しかし、より大きな露出のほうには、悪意ある行為者がそもそもいない。開発者の作業ツリー、git の履歴、伏せ字なしの .env の秘密情報の 5.10 GiB が、攻撃者もインジェクションも越えられた境界もないまま、ツールの既定の経路でベンダーのバケットへ届く — これは前提を経ずに辿り着かれた、この仮説の結論のより強い版であり、ゼロトラストが、それを覆す敵対者に対してだけでなく、ベンダー自身の出荷したバイナリに対してこそ負われていることを示す。この日が本当に切り込むのは、安全策を強制する仕組みのほうだ。この仮説は、その構造的な答えを、名前の付いた CVE のブロックリストと悪用が知られている脆弱性の期限を通じて追跡される調達のゲートに置くが、700万人を超える利用者を抱えるエディタのコード実行の欠陥に、7か月を経てもなお CVE も深刻度のスコアもない以上、修復状況を問うどのゲートも、それに働きかけようがない — 本日、安全策はゲートより手前で、脆弱性が名前を得るはずのその地点で機能しなかった。「先端はクラウド、日常はローカル LLM」の主軸は、長く惜しい外れが続いた末に、そのローカルの側で最良の証拠を得た。ここ最近のローカル基盤のデータ点は、データセンター向けの Instinct アクセラレータ、次いで 2,070 TFLOPS のロボット用モジュールと、いつも間違ったハードウェアの階層に降りてきたが、Bonsai 27B は、この仮説が実際に挙げるコンシューマ端末という終着点に降り、下限を汎用品の 24 GB のカードより一桁下へ動かして、この仮説自身のコンシューマ GPU の枠組みに時代を刻んだ。ここから正直な差し引きが3つ導かれる — 毎秒134トークンと163トークンは RTX 5090 の上で測られたので携帯端末の話はメモリに収まるという議論にとどまり、PrismML はオープンウェイトと並んで Together AI 経由のホスティングも提供しているのでこの成果物でさえクラウドの足を残し、1.125ビットでの90%の保持率が含意する学習の費用は担い手を資金を持つ研究室へと絞り込む。そしてクラウド・先端の極も価格の原動力も、どちらも沈黙したままだ。「RL/LLM ベースの予測性能向上」の主軸は、差し引きで減点を受ける。基盤の軸は静かで、Bonsai は学習のレシピではなく推論の側の符号化の結果であり、その土台は、この軸が追跡する混合エキスパート(MoE)の背骨ではなく dense な 27B のモデルだ。実世界配備の軸はカレンダーだけで、全身操作をつながれずにオンボードの計算能力の上で走らせたと報告したヒューマノイドのプラットフォームは一つもない。そしてガバナンスの軸こそ、この日が実際に噛みつくところだが、噛みつく向きが悪い — テナントごとの権限ゲートというこの軸の中核をなす基本要素は、Grok CLI のアップロードが一度も通らないオーケストレーションの層に位置するからだ。x402 の監査は同じ軸へ、このサイクルで最も冷や水を浴びせる数字とともに届く — 確かめられるほど公開されている唯一のエージェント配備の指標は、確かめに耐えなかった。本日の差し引きは、いつになく偏っている。3つの新しい予測が、損なわれずに届いた起点の証拠の上に立つ一方で、既存の予測群は本物の修正を受け止める — 本日の露出は現実のものであり、それに応えると既存の予測群が見込んでいる制御の大半は、そのどちらも見えなかっただろう。
