## Future


1. Inkling が Q2 2027 までに、ハイパースケーラーのマネージドファインチューニングの品目に載る

   Thinking Machines は7月15日、初のゼロから学習したモデルとして Inkling を公開した。総パラメータ 975B / アクティブ 41B の Mixture-of-Experts で、45兆のマルチモーダルトークンで学習され、オープンウェイトとして、総パラメータ 276B の Inkling-Small プレビュー版とともに出荷された。このリリースは、最強のモデルだとは一切うたっていない。賭けているのは、企業が求めるのは借り物のフロンティアのエンドポイントではなく、自分たちでファインチューニングできるベースモデルだという読みであり、ウェイトは同社の有償ファインチューニング基盤である Tinker へそのままつながる。発売をめぐる配布の形が、その裏づけになっている。Together AI は初日から OpenAI 互換のエンドポイントの背後で Inkling の提供を始め、Unsloth は v0.1.49-beta で即日対応を果たした。つまり、サードパーティの提供と調整のスタックが、ニュースサイクルのうちに出来上がったのだ。ビッグ3のクラウドは、すでにマネージドファインチューニングのカタログの広さで競っている。そして、商業上のアイデンティティ全体がファインチューニングのしやすさにあるフロンティア規模のオープンウェイトのベースモデルは、まさにそのカタログが取り込む種類の成果物である。予測はこうだ。Q2 2027 までに、ビッグ3のハイパースケーラーの少なくとも1社が、Inkling または Inkling-Small を、単なる素のホスティングではなく、ファーストパーティのマネージドファインチューニングの対象として掲載する。それは、Thinking Machines のファインチューニング第一の公開戦略を、ハイパースケーラーの企業向けカスタマイズ製品の棚に並ぶ商品へと変えるものだ。


   In plain language: 大手 AI ラボが、企業が再学習できるようにと巨大モデルを無償で公開した。まもなく大手クラウドが、その再学習をサービスとして売り出すだろう。


2. Microsoft、Q2 2027 までに、AI 関連の修正で Patch Tuesday の月次の周期を破る

   Microsoft は、自社の AI 関連の領域を月次の Patch Tuesday のリズムから切り離し、月次より速いセキュリティ提供の周期で出荷するようになる。7月14日のリリースは過去最多の570件の脆弱性を修正したが、目を引いたのは件数だけでなく、その内訳だった。Microsoft Copilot 自体における致命的なリモートコード実行の欠陥(CVE-2026-48561)、GitHub Copilot の RCE、Copilot/VS Code のセキュリティ機能バイパス、Copilot/VS Code のトークン漏えいの欠陥。アシスタントと、それを載せるエディタは、もはや珍しい一度きりの話ではなく、繰り返し現れる脆弱性の区分を成している。Microsoft はこの記録的な件数を、自社の AI を使った内部の脆弱性発見システムによるものだと説明している。つまり、これらの発見を生み出すパイプラインは、これからも加速し続ける。同じ圧力を受けた Adobe は、同じ日に月2回の情報公開へ移行し、AI で加速した発見が、開示から悪用までの時間を縮めていることを理由に挙げた。オペレーティングシステムの部品のために設計された月次の一括方式は、欠陥が絶え間なく見つかり、すばやく武器化される、クラウドで更新されるアシスタントにはそぐわない。Copilot の修正はもともと大部分がサーバー側で配備されるため、切り離すエンジニアリングの費用は低く、一方で月次の便に修正を留め置く露出の費用は上がり続ける。予測はこうだ。Microsoft がこれを正式なものにする。すなわち、Copilot 級のサービスに対する、公に文書化された加速された周期、または AI 関連の領域に特化したセキュリティ提供チャネルのいずれかを、Q2 2027 までに発表する。


   In plain language: 攻撃者も守る側も AI でバグを速く見つけるようになったので、Microsoft は Copilot のセキュリティ修正を、月1回より頻繁に出すようになるだろう。


3. TSMC の 2nm ノード、Q2 2027 までにウェハ売上の20%へ

   TSMC の2026年第2四半期決算は、2ナノメートルノードを、初めて意味のある数字が出た四半期でウェハ売上の3%と位置づけた。しかも記録ずくめの決算のなかでの話だ。売上高は US$40.20 billion で前年同期比36%増、純利益は77.4%増、粗利益率は67.7%である。予測は、2nm が先代のたどった軌跡を繰り返すというものだ。3nm は一桁前半のわずかな比率でデビューし、いまではウェハ売上の30%を握っている。そして同社は、2nm にも同じ急峻さを予告している。CFO の Wendell Huang は、「2ナノメートル技術の急峻な立ち上がり」を根拠に第3四半期の売上を US$44.6-45.8 billion とはっきり見通し、2026年の設備投資計画は US$60-64 billion へ引き上げられた。この支出は、最先端の生産量が速く伸びてはじめて回収できるものだ。需要側は、すでに約束済みである。NVIDIA と AMD の AI アクセラレータのプログラム、旗艦スマートフォンのシリコン、オンデバイス NPU のロードマップが、いずれも同じ最先端のウェハに列を作っており、TSMC は需要を、価格ではなく供給によって割り当てられるものと説明している。デビューから4回の決算のうちに、すなわち2027年6月に終わる四半期には、2nm はウェハ売上のおよそ5分の1に達し、3nm が 5nm を置き換えたのと同じように、3nm に代わる成長の牽引役となるはずだ。


   In plain language: TSMC の最新のチップ製造プロセスが、初めて売上を計上した。前の世代と同じように育てば、1年のうちに売上の5分の1を占めるようになる。
