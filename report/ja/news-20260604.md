1. オープンなエージェントハーネスが2026年第4四半期までに2社目のベンダーの自社製エージェントを動かす

   オープンソースのエージェントハーネスが、ブランドを冠した自社製ベンダーエージェントの中核エンジンとして組み込まれる、という構図が、2026年第4四半期までに2社目の主要ベンダーでも繰り返される軌道にある。これが確認されれば、独自の統制機構で包まれたオープンな中核というのが、一度きりの出来事ではなく構造的なパターンであることを裏付ける。今週のMicrosoftのBuildの基調講演はその形を明確に示した。Microsoft Scoutは、同社初の常時稼働する「Autopilot」型の業務用パーソナルエージェントで、Teams、Outlook、OneDrive、SharePointに組み込まれている。そしてその動力源は、オープンソースのローカルエージェント基盤であり、本ブリーフが追う3つのオープンなコーディング/エージェントハーネスの1つであるOpenClawだ。MicrosoftはOpenClawを隠れた社内スタックへフォークしたのではなく、オープンなハーネスをそのままランタイムとして出荷し、その上に企業向けの統制機構を重ねた。各Scoutエージェントは、スコープを絞った権限と監査証跡を伴う統制されたEntra IDの下で動き、継続的なポリシー適合チェック、データが外部へ出る前のPurviewによるデータ保護の適用、そしてWork IQという文脈層を備える。これが一般化する理由は、企業向けベンダーにとって難しく差別化につながる仕事が、いまや統制の包み、ID、製品としての作り込みであり、エージェントのループそのものは、ベンダーが作り直すのではなく採用できる、解決済みで実戦に耐えるオープンな部品になっているからだ。これはエンジンに関する従来の自作か購入かの判断を逆転させる。独自のエージェントランタイムを再実装しても、保守されたオープンなハーネスを組み込み、統制と流通で競うのに比べて、ほとんど優位が得られない。したがって注視すべき将来の状態は、主要なプラットフォームベンダーまたは生産性ベンダーから出る2つ目のブランド付き自社製エージェントが、追跡対象のオープンなハーネス（OpenClawまたはその同類）の1つを基盤ランタイムとして開示し、そのベンダー自身のID、ポリシー、データ統制で包んでいることである。これを確認するシグナルは、ブランド付きの企業向けエージェントのエンジンとして特定のオープンなハーネスを名指すローンチ、プレビュー、または技術的な開示だ。年末までに競合各社が、代わりに自社製のクローズドなランタイム上でエージェントを出荷すれば、このパターンは確認されない。


   In plain language: Microsoftの新しい業務用エージェントはオープンソースのエージェントソフトの上で動き、自社の統制を加えている。だから別の大手企業もまもなく同じことをする。

   In plain language: あまりに多くのAI・ロケット企業が一斉に株を売り出そうとしているため、投資家は価格を下げずにすべてを買うだけの現金を持っていないかもしれない。

### Microsoftが、OpenClaw上に構築されMicrosoft 365に組み込まれた常時稼働の業務用パーソナルエージェントScoutを発表

- Microsoftは今週のBuildの基調講演でMicrosoft Scoutを発表した。これは同社が初の「Autopilot」と位置づける常時稼働のパーソナルエージェントで、継続的に動き、自身のIDを持ち、サイドバーのプロンプトを待つのではなくユーザーに代わって行動する、新しい一群のエージェントだ。Scoutはクラウド、デスクトップ、Webにまたがって動き、Teams、Outlook、OneDrive、SharePointへ直接つながる。チャット、メール、カレンダー、連絡先という一日の業務を構成する要素に届くため、ユーザーが文脈を切り替えることなく、それらのアプリ間でスレッドを読み、データを取り出し、文書を起草し、会議を設定し、タスクを追いかけられる（[Microsoft 365 Blog - Introducing Microsoft Scout: Your always-on personal agent](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/02/introducing-microsoft-scout-your-always-on-personal-agent/)による）。本プロジェクトの取材にとっての要点は、Scoutが何の上に構築されているかだ。動力源はオープンソースのローカルエージェントプラットフォームであるOpenClawであり、Microsoftがそれを自社の企業向け統制機構で包んでいる。各Scoutエージェントは、共有のサービスアカウントではなく、統制されたMicrosoft Entra IDの下でスコープを絞った権限とともに動き、監査証跡、継続的なポリシー適合チェック、そしてデータが外部へ出る前に適用されるMicrosoft Purviewによるデータ保護を備える。さらにWork IQという層が、ユーザーの働き方と次に起こすべきことを学び、文脈を引き継いでいく。提供範囲はローンチ時点では意図的に限られている。Microsoftの従業員が社内で動かしてきた初期のデスクトップビルドが、Frontierの早期アクセスプログラムを通じて一部の顧客にプライベートプレビューとして拡大されたもので、Frontierへの登録、Intuneのポリシー設定、オプトインの同意表明、GitHub Copilotライセンスを条件とし、より広い順番待ち式のプレビューは2026年後半に予定されている（[Thurrott - Build 2026: Microsoft Unveils New 'Scout' Personal Work Agent Powered by OpenClaw](https://www.thurrott.com/a-i/336926/build-2026-microsoft-unveils-scout-personal-work-agent-and-new-in-house-ai-models)による）。通底するのは、本ブリーフが追う3つのオープンなコーディング/エージェントハーネスの1つであるOpenClawが、いまやTeamsとOutlookの中に参加者として直接置かれたMicrosoftの自社製品のエンジンになっているという点だ。 [Microsoft 365 Blog - Introducing Microsoft Scout: Your always-on personal agent](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/02/introducing-microsoft-scout-your-always-on-personal-agent/), [Thurrott - Build 2026: Microsoft Unveils New 'Scout' Personal Work Agent Powered by OpenClaw](https://www.thurrott.com/a-i/336926/build-2026-microsoft-unveils-scout-personal-work-agent-and-new-in-house-ai-models)


### NvidiaがNemotron 3 Ultra 550Bのオープンウェイトを公開、これまでで最も能力の高い米国のオープンウェイトモデル

- Jensen Huang氏が6月1日のComputexでプレビューしたNemotron 3 Ultraのウェイトが、本日Hugging Faceで公開された。NvidiaのNVIDIA Nemotron v3コレクションには、新たにアップロードされた3つの形態で5,500億パラメータのUltraが並ぶ。命令チューニング済みの`NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16`、`Base-BF16`の事前学習チェックポイント、そして`NVFP4`の量子化ビルドであり、これに加えて生成型の報酬モデルもある（[Hugging Face - NVIDIA Nemotron v3 collection](https://huggingface.co/collections/nvidia/nvidia-nemotron-v3)による）。このモデルは、トークンあたり約550億パラメータがアクティブになる混合エキスパート（MoE）設計で、100万トークンの文脈ウィンドウと、毎秒300超のトークン出力を謳い、Nvidiaはこれをチャットではなく複数ステップのエージェント推論のためにゼロから設計した初のオープンモデルと位置づけている。独立系のArtificial Analysis Intelligence Indexでは48を記録し、これによりこれまでに公開された米国のオープンウェイトモデルとして最も強力となり、他のあらゆる米国製オープンモデルを上回る。ただし依然として中国のKimi K2.6の54には及ばないため、「最良のオープンモデル」という主張は米国勢の中でのみ成り立つ（[Implicator.ai - Nvidia's Nemotron 3 Ultra leads US open models but trails China's Kimi K2.6](https://www.implicator.ai/nvidias-nemotron-3-ultra-leads-us-open-models-but-trails-chinas-kimi-k2-6/)による）。ウェイトはオープンライセンスで出荷されるが、実務上の難点はハードウェアだ。550Bのモデルは自前で動かすにはデータセンター級のメモリを要するため、多くのチームはOpenRouterやbuild.nvidia.comのNIMエンドポイント経由で利用することになり、このオープンな公開はNvidiaのシリコンへの導線も兼ねている――同梱されるCUDA-Xのスキルライブラリ群はNvidiaのGPU上で最もよく動く。ローカルLLMを作る人にとってより即座に動かしやすいのは、同じv3ファミリーのより小さなNano（4B/30B）とSuper（120B）であり、コレクション内の量子化形態のおかげで単一ノードのハードウェアでも扱いやすくなっている。 [Hugging Face - NVIDIA Nemotron v3 collection](https://huggingface.co/collections/nvidia/nvidia-nemotron-v3), [Implicator.ai - Nvidia's Nemotron 3 Ultra leads US open models but trails China's Kimi K2.6](https://www.implicator.ai/nvidias-nemotron-3-ultra-leads-us-open-models-but-trails-chinas-kimi-k2-6/)


### MicrosoftのSurface RTX Spark Dev Boxが、RTX Sparkスーパーチップを机上に置き、オンデバイス推論向けのFoundry Localとともに出荷される

- Microsoftは、今月初めにGTC Taipeiで披露されたNvidia/MediaTekのGrace-Blackwell部品であるRTX Sparkスーパーチップを開発者向けワークステーションに仕立て、BuildでSurface RTX Spark Dev Boxを発表した。この卓上の筐体は、Nvidia Blackwell RTXのGPUとGrace CPU、128GBの統合メモリを組み合わせて最大1ペタフロップのAI計算能力を実現する。これは1,200億超パラメータのモデルを100万トークンの文脈で完全にローカルで動かすのに十分だ。Windows 11 Proを実行するSecured-core PCとして出荷され、GPUパススルーとCUDA向けに事前設定されたWSL 2、VS Code、GitHub Copilot、VS Code向けAI Toolkitを備え、組織向けにはEntra IDとIntuneで管理される（[Microsoft Devices Blog - Building the next generation of devices for developers: Surface RTX Spark Dev Box](https://blogs.windows.com/devices/2026/06/02/building-the-next-generation-of-devices-for-developers-surface-rtx-spark-dev-box/)による）。Microsoftはこれを今年後半にMicrosoft.com限定で出荷される発売前のデバイスとして掲載しており、オンデバイスのソフトウェアスタックはTensorRTを伴うWindows ML、Windows Copilot Runtime、そしてローカルの試作品をクラウドの配備パイプラインへつなぐMicrosoft Foundryを中心に構成されている。組み込み/エッジのローカルLLM作業に関わる要点はFoundry Localだ。これはMicrosoftのオンデバイスランタイムで、Azure AI Foundryのクラウドマーケットプレイスとは別物であり、4月に一般提供に達し、5月末に1.1と1.2の更新を出荷した。これらの更新では、Nemotron ASRモデルによるライブ音声書き起こし、オンデバイスのテキスト埋め込み（qwen3-0.6b-embedding）とQwen 3.5 Visionのマルチモーダル推論、ダウンロード可能なWebGPU実行プロバイダー、Linux ARM64対応、そしてPython、JavaScript、C#、Rustの各SDKにわたるONNX Runtime 1.26への引き上げが加わった（[Microsoft Foundry Blog - What's new in Microsoft Foundry, May 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-may-2026/)による）。両者が合わさって描くのが、MicrosoftのローカルAIの売り込みだ。約20MBのネイティブライブラリに収まる厳選されたオンデバイスランタイムと、クラウドの外でフロンティア級のオープンモデルを動かせる規模の自社製ハードウェアの組み合わせである。 [Microsoft Devices Blog - Building the next generation of devices for developers: Surface RTX Spark Dev Box](https://blogs.windows.com/devices/2026/06/02/building-the-next-generation-of-devices-for-developers-surface-rtx-spark-dev-box/), [Microsoft Foundry Blog - What's new in Microsoft Foundry, May 2026](https://devblogs.microsoft.com/foundry/whats-new-in-microsoft-foundry-may-2026/)
