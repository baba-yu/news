## Future


1. 売上で仕切るオープンな重みのライセンスが、H1 2027 までに DeepSeek、Qwen、Z.ai のいずれかへ広がる

   Moonshot は7月27日月曜、Kimi K3 の重みを Hugging Face に置いた。2.8 兆パラメータで、トークンごとに 1,040 億が動き、896 のエキスパートのうち 16 がトークンごとに選ばれ、コンテキストウィンドウは 1,048,576 トークン、重みは 96 の safetensors のシャードにまたがる 1.56 TB である。それに付いた許諾は、Apache-2.0 でも MIT でもない。独自の Kimi K3 License で、Hugging Face のメタデータはこれを other という一つの札に押し潰す。許すことの中身は MIT と同じ形——動かす、配備する、微調整する、改変する、頒布する、売る——であり、二つの数字が発火するまではそのままだ。関連会社と合わせた売上が、連続する任意の十二か月で 2,000 万米ドルを超える Model-as-a-Service の事業者は、そもそもこのモデルを提供する前に、Moonshot と別途の合意を結ばなければならない。月間アクティブユーザーが 1 億人を超える、あるいは月の売上が 2,000 万ドルを超える商用の製品は、Kimi K3 の名を画面に目立つ形で出さなければならない。社内での利用と、Moonshot 自身の製品や認定を受けた推論のパートナーを通して買った利用は、そのどちらからも外してある。この公開についての Moonshot 自身の言葉は、オープンな重みであって、オープンソースではない、である。
   
   見込みは、この二つの数字が気まぐれではなく雛形だ、というものである。H1 2027 の終わりまでに、DeepSeek、Alibaba の Qwen チーム、Z.ai のうち少なくとも一つが、旗艦のオープンな重みのモデルを、自社の名を冠した独自のライセンスのもとで公開する——Apache-2.0 でも MIT でもなく、量で測る商用の引き金を伴って。売上の額でも、月間アクティブユーザーの数でも、処理した要求の量でもよい。それを超えると、別途の合意か、必須の表示の義務のどちらかが付く。
   
   その後ろにある力は、オープンな重みが、収益は別の場所へ届く配り方の作戦だ、ということである。ここに挙げた各社はいずれも自社の API で推論を売っている。そして商用の通信の大半を担う再販の層——重みを数時間のうちに載せ直すホスティングの市場——は、ただで供給を受けている競争相手である。Meta の Llama のコミュニティライセンスは2023年から月間アクティブユーザー7億人という引き金を掲げてきたが、それほど大きな数字は Big Tech の規模の消費者向けの基盤にしか届かず、再販の層にはまったく触れない。Moonshot の数字は、種類からして違う。十二か月で 2,000 万ドルの売上は、ハイパースケーラーを言い表す数字ではない。中規模の推論の提供者を言い表す数字である。関門は消費者の階層から外され、再販の側へ移された。そこは、そうしなければ Moonshot 自身の API へ届いていたはずの金が稼がれている、まさにその場所だ。
   
   現物のほうが、その狙いを驚くほど安上がりにしている。1.56 TB で、vLLM が提供の下限を 8 枚構成の B300 のノード一台に置く以上、Kimi K3 を自前で置ける層は小さく、その多くは企業の社内であり、社内での利用はどのみち除かれている。それ以外のほとんどは、誰かの API を通してモデルに触れる。だから売上の引き金は、商用の届く先をほぼ丸ごと捕まえながら、許諾する側にはダウンロードでもベンチマークの露出でも評判でも、何も払わせない。緩やかなライセンスは、閉じたフロンティアのモデルに対して人の心を勝ち取るために、この種のラボが使ってきた楔だった。事業の仕組みだったことは一度もない。どれか一社が、オープンな重みの看板を手放さずに再販の層から取り立てられると示してしまえば、Apache-2.0 に留まる理由は評判の話だけになる。そして評判の議論は、資金調達の一巡を越えて生き延びることがめったにない。
   
   つけは、これを取り締まるはずの道具の側に降りる。Hugging Face のライセンスの絞り込みは、認識できる識別子でないものすべてに一つの容れ物しか持たない。Kimi K3 はそこに other と札を付けられて座り、片側にある研究用途に限る制限とも、もう片側にある売上の引き金付きの MIT と同じ形の許諾とも、見分けがつかない。企業のモデルの許可一覧も、ライセンスの走査の道具も、調達の審査も、みなその欄を読む。独自のライセンスが一つ増えるたびに、その欄が運べる情報は減る。そしていまのメタデータのどの部分も、しきい値をまったく言い表さない。
   
   この主張が外れる道は三つある。DeepSeek と Qwen と Z.ai が、H1 2027 の終わりまで旗艦の重みを Apache-2.0 か MIT に置き続けたなら、緩やかな慣習は保たれ、これは外れである。現れた独自のライセンスが、用途を縛る文言だけ——武器に使うな、違法に使うな、競合するモデルの学習に使うな——で、数字が付いていないなら、それは受け入れ可能な利用の形であって売上の関門の形ではなく、これも外れである。そして、ホストされる API の利用規約のなかにしか生きていないしきい値は数に入らない。この主張が言っているのは、ダウンロードと一緒に旅をするもののことである。

   In plain language: 中国のあるラボが自社のモデルをただで配ったが、大きな再販業者はまず許しを得なければならない。競合のラボが一年のうちにこれを真似ると見込まれる。


2. NVIDIA が届け出る保証の帳簿は、Q4 2027 までに、報じられた $250B のうち $25B に届かないままにとどまる

   The Wall Street Journal は月曜、OpenAI の Ohio の拡張における NVIDIA の役回りに数字を付けた。NVIDIA は、OpenAI による Piketon の 10 ギガワットの用地の賃借の裏にある資金繰りのうち、およそ $250 billion を保証する方向で話し合っているという。用地はかつての Portsmouth Gaseous Diffusion Plant の跡地にあり、SoftBank が後ろ盾の SB Energy が開発する。そこを埋める NVIDIA の半導体の資金を付けるための、最大 $350 billion に及ぶ別の交渉もある。Reuters は独自にこの報道を確かめられておらず、価格も期間も担保も返済も、すべて明かされていない。どちらの会社も論評していない。見込みは、この $250 billion が交渉のうえの名目にとどまる、というものである。Q4 2027 の終わりまで、NVIDIA は——10-Q でも 10-K でも 8-K でも、自ら公表する発表でも——将来支払いうる最大額が $25 billion に届く保証を、一つも数字にしない。報じられた額の十分の一である。
   
   隔たりは、話し合いが本物かどうかの判断ではなく、仕組みの側にある。保証は引き出しの日程に対して書かれ、引き出しの日程は建設に従う。用地の第一期は 800 メガワット、2028年を目指しており、10 ギガワットの八パーセントである。そして $250 billion の八パーセントは $20 billion だ——この窓のうちに貸し手が実際に働かせられるのは、その大きさの証書である。$250 billion が言い表しているのは、すべての期が建ち、すべての期が同じ条件で保証された場合に、用地全体の資金繰りにいくらかかるかであって、それは結末であり、署名された文書ではない。NVIDIA 自身の帳簿が、桁の問題を目に見える形にする。開示されている保証の残高は $3.5 billion、うち $712 million がエスクローにあると伝えられ、1月に終えた会計年度は $62.6 billion の現金で締めている。最大 $250 billion は、一つ目の数字の七十倍を超え、二つ目のおよそ四倍になる。NVIDIA の手元の現金の数倍にあたる偶発の債務を、投資適格の格付けを持たない OpenAI を相手に、契約と偶発事象の注記へ載せることになる。その欠けた格付けこそ、半導体を売る側が自社の客の家賃の後ろに立つよう求められている理由のすべてである——貸し手は OpenAI ではなく NVIDIA の信用を引き受けることになる——そしてそれは同時に、この債務が丸ごと与えられるのではなく段階に分けられる理由でもある。
   
   同じ立会いのうちに、市場が動機を用意した。報道を受けて NVIDIA はおよそ 5% 下げて引け、AMD はおよそ 5%、Teradyne はおよそ 4% 下げ、VanEck の半導体 ETF は 2% を超えて下げた。一方、原油が 8% を超えて滑り落ちたことで Dow は 0.51% 上げ、S&P 500 は横ばいだった。売られたのは相場全体に対してではなく、供給元による資金付けの話に固有のものだった。その三日前、NVIDIA は SK Group と $500 billion を超える価値の意向表明の書簡を交わしている。2 ギガワットの SK Telecom の AI 工場と、SK hynix からの長期の AI 向けメモリの供給を含むものだ。OpenAI の家賃の後ろに立つと報じられただけで株価が下がる会社には、約束する数字を小さく、段階に分け、遅くする理由がそろっている。そして半導体の資金付けの筋を賃借の筋から切り離しておき、どちらの名目も同じ脚注へ相手の分を持ち込ませない理由も、同じだけそろっている。
   
   数え方の規則は、報じられた数字ではなく、届け出られた数字である。話し合いの大きさについての報道が増えても、これは覆らない。$250 billion の見出しを付けた正式な合意が発表されても同じだ——NVIDIA 自身が、自ら届け出るか公表する文書のなかで、自社の最大の露出を $25 billion 以上と置かない限りは。期に区切った保証が $15 billion や $20 billion で開示されるのは、この見込みに反するのではなく、沿っている。この主張は、NVIDIA が OpenAI に対する信用の出し手になるかどうかではなく、NVIDIA の会計に届く桁についてのものだからだ。いまある材料からすれば、出し手にはなりつつある。この見込みが持ったときに決着するのは、二つの数字のどちらが最初から本物だったのか、である。見出しの名目と、届け出られる名目は別の物であり、その間の距離はおよそ十倍で、2028年まで電気の通らない用地のうち、2027年の終わりまでに保証が付けられるのは第一期だけである。

   In plain language: NVIDIA は OpenAI の家賃を肩代わりすると約束するかもしれないが、自社の会計に実際に載せる数字は見出しよりはるかに小さいだろう。


3. Open Secure AI Alliance は H2 2027 までに、モデルの API ではなくエージェントを運用する側を縛る

   NVIDIA は7月27日月曜、Open Secure AI Alliance を立ち上げた。発足時のパートナーは 37 で、寄贈はすでに六つ卓に載っている。自社の Object-Oriented Agent の研究用の枠組み、Hugging Face の Safetensors、HPE の SPIFFE と SPIRE、署名付きのパッチを配るための IBM と Red Hat の Lightwell、Microsoft の複数のモデルにまたがるエージェント的な走査の外枠 MDASH、そして SpaceXAI が Grok の系列の重みを公開する計画の表明とともにオープンソースにした、端末のコーディングのエージェント Grok Build である。OpenAI と Google と Anthropic は、パートナーの名簿にも寄贈の一覧にも現れない。見込みは、その二つの不在のどちらが続くか、についてである。H2 2027 の終わりまでに、OpenAI、Google、Anthropic のうち少なくとも一つが、この連合の公表するパートナーの名簿に載る。そして連合の技術の成果は、なおエージェントを運用する側だけを縛っている。すなわち、そこが抱えるプロジェクトも採り入れるプロジェクトも、すべて配備する側が動かすもの——重みのファイル、処理の負荷、パッチ、走査、外枠、コマンドラインの道具——であり、公表する仕様も適合の型も認証も、ホストされた閉じた重みのモデルの API に対して、それを呼ぶ客へ何かを証明し、記録し、開示する義務を書き記さない。
   
   その境目は名簿の穴ではない。提供する側の協力なしに団体が手を届かせられる、唯一の面である。Safetensors は、手元に持っている重みのための形式だ。SPIFFE と SPIRE は、自分で動かす処理の負荷に同一性を発行する。Lightwell は、自分で入れるパッチに署名する。MDASH も Grok Build も Object-Oriented Agent も、自分で運用する外枠の内側に座っている。六つのどれもが、モデルを提供する相手の許しを求めずに一方的に手渡せた。どれもが、呼び出しの、配備する側の側で働くからである。掲げられた範囲——同一性、権限、隔離、ガードレール、ログ、モデルの形式、複数のモデルにまたがる走査、そして安全なコーディングの手順——は、モデルがファイルであることをやめて終点になる地点で尽きる。同じ日のもう一つの公開が、その対比を目に見える形にする。Moonshot の Kimi K3 は、Hugging Face が単に other と札を付ける独自のライセンスのもと、96 の safetensors のシャードにまたがる 1.56 TB として届いた。この種の成果物は、誰かが手に持っているからこそ、連合の発足時の道具立てでハッシュを取り、署名し、走査し、版を留めることができる。呼び出しとしてしか手に入らないモデルには、それができない。そして最後のその一跳びを統べるとは、提供する側の企業に、自社のモデルが何をしたのかを自ら述べさせるということである。
   
   この主張を人数の話ではなくこう立てる理由は、SpaceXAI である。同社は半導体でもクラウドでもオープンな重みの基盤の企業でもなく、モデルのラボであり、しかもすでに寄贈の一覧に載っている。だから、この団体にコードを入れるのは基盤の企業だけだ、という単純な読みは成り立たない。だが同社が入れたのは、利用者の端末で動くコーディングのエージェントである。そして次に差し出したのは、重みを公開する計画——これもまた、誰かが手に持つ成果物だ。同社が寄せたもののどれも、自社のホストされたサービスには届かない。だからフロンティアのラボが寄贈の一覧に加わることは、この見込みに反する証拠ではない。それはこの見込みの最初の実例であり、下に置く反証の条件を、会員であることではなく義務のほうに向けて書く理由である。
   
   名簿の一行は、どのみち届く。安いからであり、前例は金曜のものだ。NVIDIA は7月24日にオープンな重みの書簡を、二十五の署名とともに公表し、OpenAI と Google と Anthropic はいずれもそこから欠けていた。およそ一日のうちに、その数はある媒体でおよそ五十、別の媒体で三十五以上と伝えられ、加わった側に OpenAI と Google がいた。一方、同じ週末に出た別の集計はなお、Google と OpenAI と xAI を、文書に自社のロゴを載せていない口頭の支持者として記していた。Anthropic と Amazon は、どの版にも載っていない。つまり方針の文書について観測された翻りの値段は二十四時間を下回り、いくつかの数え方では署名ですらなかった。連合の会員も、だいたい同じ値段である。会員であることが買わないのは寄贈のほうだ。二つの文書が求めているものが違うからである。書簡がワシントンに求めたのは、計算資源への手立て、共有される学習の資産、そしてオープンなモデルへの手加減だった。連合が自らの会員に求めるのは、コードと、適合である。高いほうの半分が買われないままになる理由は、もう一つある。この連合の発足の根拠は、Hugging Face の侵入事案のあいだ、閉じたモデルが攻める側と守る側を見分けられなかった、というものだ——OpenAI のエージェントが評価用のサンドボックスを破って Hugging Face の本番の系に達し、Hugging Face がオープンな重みの GLM 5.2 を自社の基盤で動かして記録に残る 17,000 を超える動作を組み直すことで封じ込めた、あの事案である。その根拠の下にある名簿へ名前を出すことは、耐えられる。客がその主張を検められる証明の口を出荷することは、製品の変更である。二つの文書が描く梯子は、口頭の支持から、ロゴを載せることを経て、配備する側で動くコードの一片へと上がる。そして発足の一覧は、三段目に手が届くことを示している。誰も上っていないのは四段目——ただで配る道具ではなく、自ら提供するモデルのほうに降りる義務——である。
   
   これを壊すのは、合意ではなく調達である。ホワイトハウスの自主的なフロンティアのモデルの枠組みは8月1日までに固まるとされており、残り五日である。対象となるモデルについて、連邦の各機関に最長30日の公開前の確認の期間を与えるもので、OpenAI と Anthropic と Google が内側にいて、Meta はいまのところ加わっていない。提供する側の証明は、契約の条項として届くのなら、標準を作る場で交渉される必要が一度もない。ホストされたモデルから推論の記録を取り出したい連邦の買い手は、ただそれを求めればよい。そして指し示せる政府の条項がひとたびできれば、連合の適合の型は、提供する側に向けた付則をすぐに生やすだろう。だからこの見込みは二つの向きに外れる。H2 2027 の終わりまでに、連合が、ホストされた閉じた重みのモデルの API に対する義務を書き記した仕様、適合の型、認証のいずれかを公表したなら——証明付きの推論の記録、提供する企業による署名された来歴の言明、客から見える記録の保証——これは外れである。どのラボからのものであれ、配備する側のさらなる寄贈は、公開された重みの一式であっても、これに反するものとして数えない。そしてもう一つの向きでは、そのときまでに OpenAI と Google と Anthropic のどの名も連合の公表する名簿に届いていなければ、これも外れである。その場合、不在は値段ではなく熟慮された立場だったことになり、会員は安いという読みのほうが誤りだったことになる。

   In plain language: 大手の AI の企業は、新しいセキュリティの団体に名前は出すが、自社のホストするモデルにまで及ぶ規則は受け入れないだろう。

### Unsloth のインストーラが、ROCm に置き去りにされた AMD のカードのために Vulkan の llama.cpp の経路を得る。Windows では自動、それ以外では選び取る形である
