## Future


1. FLUX 3 のアクションのヘッドは、H1 2027 を通じて公開されないままにとどまる

   7月23日に公開された Black Forest Labs の FLUX 3 は、画像・動画・音声・アクションをまとめて学習した一つのバックボーンであり、そこから FLUX 3 Video、FLUX 3 Image、FLUX 3 Action、FLUX 3 Dev という四つの派生が切り出されている。オープンな重みを約束されたのは Dev だけで、しかもその約束は公開時の出荷ではなく「年内」という日取りにとどまる。そもそも重みを開く理由として同社が挙げたのは、ロボットの制御はアクチュエーターを抱えた機械の上で、ホストされたエンドポイントへ往復せずに動かねばならない、という点だった。予測はこうだ。この成果物と、掲げられた理由とが離れていく。H1 2027 を迎えても、ロボットの動作を出力する FLUX 3 のチェックポイントは、公に落とせる形では現れない。FLUX 3 Dev は生成のモダリティだけを載せて出て、アクションを条件づける経路は欠けているか無効にされているか、あるいはオープンな公開そのものが約束の期限をまるごと過ぎる。その間、FLUX 3 Action は、公開時に置かれた申請制の早期アクセスの関門の内側にとどまる。
   
   仕組みはこうだ。まとめて学習したバックボーンは、モダリティの公開を、学習をやり直すかどうかの判断ではなく、ヘッドごとの判断に変えてしまう。一つのアーキテクチャが四つのモダリティを丸ごと抱えているため、重みを公開する作業はチェックポイントを切り分ける手当てになる。共有された幹は出荷され、アクションのヘッドは出荷されない。それでも出来上がった成果物は、オープンな重みという約束の字面をなお満たす。そちらへ押す力は三つある。第一に、しがらみを負っているのがアクションの能力だ。それは Black Forest Labs 単独ではなく FLUX-mimic の協業から生まれ、すでに Audi という名の挙がった産業での導入先を持つ。だから重みを開くには、画像のモデルには要らないパートナーの同意が要る。第二に、学習の入力が乏しいのもこのモダリティだ。画像と動画のコーパスはウェブ規模でかき集められるが、物体操作の軌跡はロボットの機体ごとに、物理的に集めるほかない。ロボットが新しい作業を、従来の30時間超に対しておよそ30分で覚えるという主張は、そのデータと、その上に組まれた適応の手順についての主張であって、競合がすでに近似できる幹についての主張ではない。第三に、負う責任のかたちが根本から違う。オープンな画像のモデルが吐き出すのはピクセルだが、オープンなアクションのモデルが吐き出すのはモーターへの指令だ。しかもそれは、超党派の下院の法案が最大手のモデル開発者に対する法定の停止権限を提案した、まさにその週に世に出ることになる。
   
   この見立てに逆らう材料もある。Dev という派生は、まさにオープンな一本であるために存在する。Black Forest Labs は、OpenAI と Anthropic と Google がそろって欠けているオープンな重みの書簡に名を連ねた。そして、ロボットの制御を手元で動かすことは、そもそも同社が重みを開く根拠として差し出したものだ。この見立てを覆す条件はただ一つ、そこから素直に出てくる。すなわち、H1 2027 が閉じるまでに、出力にロボットの動作を含む FLUX 3 ないし FLUX-mimic のチェックポイントが公に公開され、申請ごとの承認なしに取得できるようになることである。

   In plain language: Black Forest Labs は、新しい AI のモデルを無償で配ると約束した。ロボットを動かす部分は、たぶんその配りものには入らない。


2. OpenRouter は H1 2027 までに、支出の管理を、トークンの料金の上に載る有償の階層として収益化する

   Stripe は、$10 billion 近い価格で OpenRouter を買う交渉に入っている。これは、このモデルのルーターがおよそ10週間前の5月の資金調達で得た $1.3 billion の評価額の、およそ8倍にあたる。予測が問うのは、その数字が成り立つために、ルーター自身の価格表の何が変わらねばならないかだ。H1 2027 の終わりまでに、OpenRouter は支出の管理を、別建てで値付けした製品として収益化する——名を持つ企業向けの階層、プラットフォームないし席数の料金、あるいは予算の上限、方針に基づくモデルの選択、ベンダーをまたいだ請求の一本化を備えた、利用額を確約する契約として。しかもそれは、モデルのベンダーへ素通しするトークンに乗せる薄い上乗せとは切り離して課金される。いまのルーターは代理店型の収益構造で回っている。よその会社の推論を定価に近い値で売り直し、わずかな利ざやを取る。だから売上は他人のトークンの量にしか連動せず、ベンダーが値下げするたびに縮む。その圧縮は今週、目に見える形で現れた。Anthropic は Claude Opus 5 を Opus 4.8 と同じ 100万トークンあたり $5 と $25 に据え、タスクあたりの費用で売り込んだ。CursorBench 3.2 では Fable 5 の最良の結果に 0.5 ポイント差まで迫り、費用はおよそ半分だ。こうして買い手が経路を選ぶ軸はタスクあたりの価格になる——そして、下がっていくタスク単価の何パーセントかは、それにつれて下がる。買い手はその利ざやに $10 billion を払うのではない。払っているのは流れの上の位置に対してであり、Stripe は昔から流れをこう収益化してきた。基本の取引手数料は入場券にすぎず、利幅はその上に積まれた有償の製品に宿る、という形だ。推論に当てはめれば、その有償の層はガバナンスにあたる。誰がどのモデルを、どの予算のもとで呼べるのか、どんな監査証跡を残すのか、そしてベンダーをまたいで一枚の請求書にまとまるのか、である。エンドポイントの上に立つ切り替えの層に対して経理の部門がほんとうに求めているのはそれであり、トークンの価格にいっさい手を触れずにルーターが課金できる唯一のものでもある。この主張は、今回の取引がまとまるかどうかには依らない。報道は交渉が流動的で決裂しうると伝えており、Databricks も以前に同じ資産を検討していた。報じられた $10 billion は、いまや OpenRouter 自身の投資家も、対抗する買い手も、そこに照らして値を付ける公開の比較対象になった。この見立てを覆すものは価格表の上にある。H1 2027 の終わりまで、OpenRouter が公開する商用の条件が、推論の量ないしクレジットの購入にかかる料金だけで構成され、その傍らに別建てで値付けされたガバナンス、予算管理、企業向けの計量の製品が一つも並ばないなら、この予測は外れである。


   In plain language: Stripe は、AI のモデルを選ぶ道具に $10 billion を払うかもしれない。それに見合うには、予算を抑える機能を売り始めるほかない。


3. ユーザーが公開する AI のアーティファクトのページは、H1 2027 までに、別の配信ドメインを与えられる

   Huntress の FakeAgent の報告が描くのは、脆弱性をいっさい必要としない攻撃だ。7月21日から22日にかけて走った Bing の検索連動広告は、本物の claude.ai の URL を指していた——攻撃者が Anthropic 自身のドメイン上に公開した、公開設定の Artifact である。そこから偽の ClaudeDesktop.exe へ転送され、GPU を使ってペイロードを復号する SectopRAT がサイドロードされた。29 の組織が影響を受け、悪意あるページは削除までに 7,100 回の閲覧を集めた。転送先のドメインの登録に使われたメールアドレスは、2025年12月まで遡って少なくとも10のドメインに結びつき、そのうちの一つは以前 Operation Endgame で押収されている。何一つ破られる必要はなかった。広告ネットワークの遷移先の審査が見たのは正規のファーストパーティのドメインであり、その下流にある評判で点数を付ける仕組みのすべても、同じものを見た。予測はこうだ。いま主力の製品のドメインからユーザーの公開したページを配信している大手——Anthropic、OpenAI、Google、Microsoft——のうち少なくとも一社が、H1 2027 までにその配信先を別の登録可能なドメインへ移す。ブラウザが製品の一部ではなく別のサイトとして扱う名前へ移し、その理由が性能ではなく悪用であることを公に述べる、というものだ。背後にある構造の力は、ウェブの残りの部分がこの問いを何年も前に片付けている、という事実である。任意のユーザーが公開できる中身は、それ自身の登録可能な名前から配信される——GitHub Pages なら github.io、Google のユーザーのファイルなら googleusercontent.com、Dropbox なら dropboxusercontent.com。親ブランドの評判を借りられないように、そして親の Cookie と同一オリジンの境界の内側に座れないようにするためだ。AI のベンダーがこの一歩を飛ばしたのは、共有が成長の源泉であり、主力の製品のドメインで配ることで、公開されたページのどれもが製品そのものに見えたからである。安全上の代償は、誰かがそれを金に換えるまで理屈の上の話にとどまっていた。FakeAgent がそれを金に換えた。そして請求書が回ってくるのは、公開の機能だけでは修復できない唯一の資産——広告ネットワークもメールのフィルターもエンドポイントの防御ツールも、意図の代わりとして読み取るドメインの評判であり、攻撃者がいまや検索連動広告の枠の値段で借りられるものだ。同じ週の SharedRoot によるサンドボックスからの脱出は、一つ下の層に現れた同じ種類の失敗である。すなわち、設計として宣言されただけで、実際には強制されていない信頼の境界だ。この見立てを覆すのは、安上がりな道が持ちこたえることである。H1 2027 を通じて、Anthropic、OpenAI、Google、Microsoft のすべてが主力の製品のドメインからユーザーの公開したページを配信し続け、この種の悪用に対して、より速い削除、アップロードの検査、公開の頻度の制限、広告ネットワークへの通報だけで応じるなら、この予測は外れである。


   In plain language: 悪党たちは、AI 企業自身のサイトに公開されたページを使ってマルウェアを広めた。だからそうしたページは、別のアドレスへ移されるだろう。

### 一つのメッセージで Claude Cowork の手元の VM を抜ける手口、本物の claude.ai のドメインから配られたマルウェアの作戦、そして AI の配信のスタックに固まった CVSS 8 以上の六つの CVE

- Accomplish AI は7月23日、<a href="https://www.accomplish.ai/blog/sharedroot-escaping-claude-cowork-sandbox/">SharedRoot</a> を公表した。macOS 上での手元の実行に Claude Cowork が使う Linux の VM から抜け出す手口である。連鎖は一つのプロンプトに収まる。権限を持たないセッションのユーザーが unshare を呼んでユーザー名前空間を作り、その内側で CAP_NET_ADMIN を手に入れ、脆弱な act_pedit モジュールに対してトラフィック制御の action を仕込み、CVE-2026-46331——<a href="https://nvd.nist.gov/vuln/detail/CVE-2026-46331">カーネルのトラフィック制御のサブシステムにある「pedit COW」の領域外書き込み</a>で、Red Hat は 7.8 と評価する——を突いて、root が持つバイナリのページキャッシュを汚す。coworkd のデーモンがそのバイナリを再実行すると、ペイロードはゲストの root として走る。しかもホストのファイルシステムがまるごと、ゲストの /mnt/.virtiofs-root に読み書き可で結び付けられているため、ゲストの root はそのままホストへのアクセスになる。すなわち、利用者が実際につないだフォルダのはるか外側にある SSH の鍵やクラウドの資格情報だ。<a href="https://thehackernews.com/2026/07/claude-cowork-flaw-could-let-ai-agent.html">The Hacker News</a> は、危険にさらされた期間に手元の Cowork のセッションを使っていた macOS の利用者をおよそ 50 万人と見積もる。Anthropic はこの報告を、修正を出さないまま「参考情報」として閉じた。根拠として挙げたのは、直近 30 日以内に公表された欠陥を報奨金プログラムの対象外とする期間に、当の CVE が入っていたことである。現行の Cowork のビルドはクラウドで動くため、実務上の緩和策はパッチではなく製品の既定の設定だ。ここから引き出される構造の教訓は、一社の話にとどまらない——エージェントのゲストにホストのファイルシステムを読み書き可で結び付ければ、ゲストのカーネルにありふれた権限昇格の欠陥のどれもがホストの陥落へと変わる。しかもゲストのカーネルは、そうした欠陥を絶えず抱え込む。

同じ期間に、脆弱性をいっさい必要としない攻撃も生まれた。Huntress が記録した <a href="https://www.huntress.com/blog/fakeagent-claude-desktop-malvertising-ends-in-dotnet-rat">FakeAgent</a> は、7月21日から22日にかけて走った不正広告の連鎖だ。Bing の検索連動広告が本物の claude.ai の URL——攻撃者が公開した、Anthropic 自身のドメイン上に置かれた公開設定の Artifact——を指し、そこから偽の ClaudeDesktop.exe へ転送されて、GPU を使ってペイロードを復号する SectopRAT がサイドロードされた。29 の組織が影響を受け、悪意ある artifact は削除までに 7,100 回の閲覧を集めた。転送先のドメインの登録に使われたメールアドレスは、2025年12月まで遡って少なくとも10のドメインに結びつき、そのうちの一つは以前 Operation Endgame で押収されている。信頼されたドメインへ公開する機能は、いまや配送の経路だ。そしてそれを成り立たせているのは、まさに広告ネットワークとエンドポイントの防御ツールが頼りにしているドメインの評判である。
