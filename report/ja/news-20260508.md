### LLM関連の研究と論文

- arxivのRL推論 + エージェンティック調整波が、3つの新しいプレプリントとともに継続する。Self-Generated Process Critiques at Scale (arxiv 2605.05702) は、5月6日の検証器なしプロセス報酬パラダイムを13B + 70Bベース・モデルでのスケール研究で拡張し、人間注釈付きプロセス報酬ラベルをすべて削除しつつ、数学推論ベンチマークで6.4-9.1%の絶対ゲインを報告する。Cooperative Search Trees with Role-Asymmetric Agents (arxiv 2605.05789) は、5月6日のマルチエージェントMCTSペーパーへの正当性証明コンパニオンを提供し、役割非対称報酬構造の下での収束保証を定式化する。Adaptive Inference Compute Routing for Mixture of Specialists Across Trust Boundaries (arxiv 2605.05821) は、テナントごとの能力ゲーティング境界(Project Glasswingプリミティブ)を尊重するセキュリティ認識バリアントで5月6日の推論ルーティング・ペーパーを拡張し、ノークロステナント情報リーケージに関する形式保証を伴う41%の推論コスト削減を報告する。 [arxiv - Self Generated Process Critiques at Scale](https://arxiv.org/abs/2605.05702), [arxiv - Cooperative Search Trees with Role Asymmetric Agents](https://arxiv.org/abs/2605.05789), [arxiv - Adaptive Inference Compute Routing for Mixture of Specialists Across Trust Boundaries](https://arxiv.org/abs/2605.05821)

- DeepMindが、Unslothのルーター・オンリー学習モードに直接関連する長コンテキストRL安定性ペーパーを公表する。Stable Long-Context Reinforcement Learning via Router-Aware Advantage Decomposition (arxiv 2605.05844) は、Mixture-of-Expertsルーター決定境界に沿って方策勾配アドバンテージを分解することが、長コンテキストReinforcement Learningランの学習安定性を実質的に改善し、128Kトークンを超えるコンテキスト長で、ルーター・オンリー学習モードでフルLoRA-on-experts実効勾配信号を回復することを示す。ペーパーはUnsloth + Hugging Faceルーター・オンリーLoRA評価をベース・セットアップとして明示的に引用し、当該テクニックがこれまで超長コンテキストReinforcement Learningでルーター・オンリー・モードの使用を妨げていた長コンテキスト学習安定性ギャップを解消することを報告する。ペーパーはLlama 4 Behemoth、Kimi K2.6、Mixtral 8x22Bルーター・オンリー学習向けのUnslothレシピと同日に着地する。 [arxiv - Stable Long Context Reinforcement Learning via Router Aware Advantage Decomposition](https://arxiv.org/abs/2605.05844), [DeepMind Blog - Stable long context RL via router aware advantage decomposition](https://deepmind.google/discover/blog/stable-long-context-rl-via-router-aware-advantage-decomposition-may-2026/)
