### Googleが主要な公開ウェイトのテキスト拡散モデルとして初となるDiffusionGemmaを公開。256トークンのブロックを並列生成し、ローカル推論を最大4倍高速化。さらにUnslothによる数独ファインチューンが双方向アテンションを実演

- 6月10日、GoogleはApache 2.0のもとでDiffusionGemmaを公開した。実験的な26B（アクティブ3.8B、Mixture-of-Experts）の公開ウェイトモデルで、自己回帰的な1トークンずつのデコードを捨ててテキスト拡散を採用する。プレースホルダートークンのキャンバスから出発し、256トークンのブロックを複数パスにわたって並列に洗練していく。確信度の高いトークンを文脈として固定し、1パスあたりおよそ15〜20トークンを確定させる。これにより、同等の自己回帰ベースラインと比べて最大4倍の生成速度を実現すると、[Google - DiffusionGemma: 4x faster text generation](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/) は伝えている。本モデルはGemma 4（26B-A4B）のバックボーン上に拡散ヘッドを追加して構築され、140以上の言語にわたる256Kの文脈をテキスト・画像・動画の入力で扱える。H100では毎秒1,000トークン超、量子化時にVRAM約18GBで動くコンシューマー向けRTX 5090では毎秒700トークン超を記録する。これはGoogle DeepMindとNVIDIAの共同開発であり、vLLM、Hugging Face Transformers、MLX、NVIDIA NeMo、Unslothにわたるネイティブ対応を備え、Google Cloud Model GardenおよびNVIDIA NIM経由でのデプロイに対応する。llama.cpp対応は近日提供予定として記載されていると、[MarkTechPost - Google AI releases DiffusionGemma, a 26B MoE open model using text diffusion](https://www.marktechpost.com/2026/06/10/google-ai-releases-diffusiongemma-a-26b-moe-open-model-using-text-diffusion-for-up-to-4x-faster-generation/) は報じている。Googleはトレードオフを明言している。DiffusionGemmaの出力品質は標準のGemma 4より低いとし、本番品質の作業には自己回帰モデルを推奨する。拡散版は、高QPSのクラウド配信ではなく、速度が重要で同時実行数の少ないローカル推論に位置づけている。注目すべきは、ローンチにUnslothでファインチューンされた数独ソルバー版が同梱されたことだ。これはモデルの双方向（左から右ではない）アテンションを活用し、グリッドを制約充足問題として埋めていく。拡散という定式化が、小さなローカルモデルの速度だけでなく、どのタスクを得意とするかをも変えることの具体的な実演である。 [Google - DiffusionGemma: 4x faster text generation](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/), [MarkTechPost - Google AI releases DiffusionGemma, a 26B MoE open model using text diffusion](https://www.marktechpost.com/2026/06/10/google-ai-releases-diffusiongemma-a-26b-moe-open-model-using-text-diffusion-for-up-to-4x-faster-generation/)
