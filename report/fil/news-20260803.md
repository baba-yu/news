1. Walang default na fallback mula XET patungong HTTP ang ilalabas ng downloader ng Hugging Face pagsapit ng Q2 2027

   Ginawang generally available ng Alibaba ang Qwen3.8-Max noong Lunes, Agosto 3, sa 2.4 trilyong kabuuang parameter na may humigit-kumulang 95 bilyong aktibo kada token, at sabi nito, bubuksan ang mga weight sa susunod na linggo kasama ang mas maliit na Qwen3.8-27B. Sa parehong araw, inilathala ng Unsloth ang 2026.8.2 sa PyPI, isang release matapos ang 2026.8.1, at hindi kernel at hindi bagong pamilya ng modelo ang laman nito. Kusa nang bumabalik ngayon ang mga download mula sa XET — ang daanan ng paglilipat na ginagamit ng Hugging Face kapalit ng payak na file pull para sa malalaking repository — patungo sa ordinaryong HTTP kapag huminto ang XET, at malaki ang ibinaba ng memory na kailangan sa paglilipat. Isang linya lamang ang release note: "Unsloth now auto fallbacks to HTTP if XET stalls." Isang proyektong ang dahilan ng pag-iral ay ang pagpapakasya ng training sa mas maliliit na hardware ang gumugol ng isang buong release para lamang matapos ang isang download.
   
   Tungkol ang hula sa kung saan hindi umaabot ang ayos na iyon. Hanggang sa pagsasara ng Q2 2027, hindi pa rin nababawi ng default na daanan ng download ng huggingface_hub ang isang huminto na XET transfer sa pamamagitan ng pagtatapos ng parehong file sa payak na HTTP. Nananatili sa loob ng XET ang gawain sa pagbawi: mas maraming retry, mas mahusay na pagtukoy sa paghinto, chunk-level na resume, at mas mabilis na imprastraktura ng paghahatid. Nananatili naman ang cross-protocol na labasan sa kinalagyan nito ng Unsloth — sa proyektong tumatanggap ng file.
   
   Wala pa nito ang client sa ngayon, at ang hugis mismo ng code ang nagsasabi kung bakit. Minsan lamang nagpapasya ang daanan ng download, bago pa gumalaw ang kahit anong byte: kung XET-backed ang repository at nariyan ang hf_xet package, tinatawag nito ang XET getter; kung wala, tinatawag nito ang HTTP getter. Walang handler sa pagitan ng dalawa na kayang ilipat ang isang file mula sa una patungo sa ikalawa habang tumatakbo ito. Iisa lamang ang lugar kung saan ginagamit ng daanang ito ang salitang fallback, at isa iyong babala para sa makinang hindi kailanman nag-install ng hf_xet — naka-enable ang XET para sa repository, wala ang package, kaya bumabalik ito sa regular na HTTP download. Fallback iyon para sa isang client na hindi kailanman nagkaroon ng mabilis na daanan, hindi para sa isang paglilipat na nawalan nito. Ganoon din ang hangganang ipinapahayag ng HF_HUB_DISABLE_XET: binabago nito kung aling daanan ang pipiliin, hindi kung ano ang mangyayari kapag namatay ang napiling daanan.
   
   Hindi haka-haka ang pagpalyang sana ay hinaharangan nito. Sinasabi ito ng dalawang bukas na ulat sa mismong tracker ng huggingface_hub. Sa Issue #4520, na isinampa noong Hulyo 11, basta na lamang tumitigil sa pag-update ang progress bar at ang XET log sa isang malaking pull. Ang Issue #4349, na isinampa noong Hunyo 12, ang siyang detalyeng nagpapahirap sa fallback kaysa sa dating pakinggan nito: kapag naka-disable na ang XET, wala namang sariling awtomatikong retry ang payak na daanan ng HTTP, at namamatay ito sa 17.3 ng 42.5 gigabyte nang walang natitira sa cache na mapagpapatuloyan. Hindi malinaw na mas maaasahan ang labasan kaysa sa mismong tinatakasan nito.
   
   Ang puwersang nagkukulong sa ayos na iyon sa loob ng XET ay ito: produkto ang XET, hindi detalye ng transportasyon. Ito ang daanang itinayo ng Hugging Face kapalit ng ordinaryong file pull para mismo sa ganitong mga repository. Tatlong bagay ang sabay na ginagawa ng isang default na iiwan ito sa sandaling huminto ito. Inaamin nito sa mismong ipinadalang code na hindi mapagkakatiwalaan ang storage layer sa mga artefact na pinaggawan dito. Itinatapon nito ang anumang bahagyang estadong naipon na ng paglilipat, at buo nitong sinisimulan muli ang file sa mas mabagal na ruta. At inaalis nito ang presyong siyang gumagawa ng tunay na solusyon. Ipinapadala ng mga vendor ang retry. Karaniwang hindi nila ipinapadala ang pag-amin.
   
   Ang laki ang nagpapalit sa isang abala tungo sa isang puwang na istruktural. Umabot sa 1.56 terabyte sa 96 na shard ang inilathalang mga weight ng Kimi K3, at kaparehong klase ang isang artefact na may 2.4 trilyong parameter. Ang 27B na kapatid nitong isinasabay sa paglabas ay isang pahayag tungkol sa kung para talaga kanino ang flagship. Sa ganoong laki, hindi isang pindot ang pull kundi isang trabahong tumatakbo nang ilang oras sa isang koneksyong tiyak na mapuputol nang hindi bababa sa isang beses, at bumababa ang tsansa ng malinis na unang subok sa bawat dagdag na shard. Hindi mga indibidwal na naghahatak ng weight papasok sa iisang makina ang sumasalo nito. Mga tagapamagitan ito na minsan lamang kumukuha ng reference na weight at naglalathala uli ng mas maliit na bersyon — sila ang populasyong pinagsisilbihan ng Unsloth, at sila ang dahilan kung bakit parang release note na ng isang transfer library ang nababasa sa kanila.
   
   Isang inilabas na bersyon ang magpapasya nito, hindi isang roadmap. Mali ang hula kung, sa o bago ang pagsasara ng Q2 2027, may inilabas na huggingface_hub na nakatutukoy ng huminto o nabigong XET transfer at tinatapos ang parehong file sa payak na endpoint ng HTTP nang walang naka-set na environment variable at walang exception handling na isinulat ng tumatawag, at makikita ito sa release notes o sa mismong daanan ng download. Tatlong bagay ang hindi binibilang laban dito. Ang mas maraming retry, mas mahusay na pagtukoy sa paghinto, chunk-level na resume o mas mabilis na imprastraktura sa loob ng XET ang mismong hinuhulaang kalalabasan, hindi ang pagsalungat dito. Ang isang mas magiliw na HF_HUB_DISABLE_XET ay pasya pa ring ginagawa bago gumalaw ang unang byte. At ang mga proyektong mas nasa ibaba pa na maglalabas ng sarili nilang labasan — isang serving runtime, isang local runner, isang mirror — ay nagpapatunay sa sinasabi sa halip na sumira dito, dahil ang punto ay patuloy itong isinusulat ng kung sino ang tumatanggap ng file at hindi ng kung sino ang nagpapadala.

   In plain language: Madalas huminto ang pag-download ng napakalalaking modelo ng AI. Patuloy na aayusin ng Hugging Face ang sarili nitong sistema sa halip na lumipat sa lumang payak na paraan ng pag-download.


2. Kukunin ng mga vendor ng autonomous na pentest ang akreditasyong AI ng CREST pagsapit ng Q2 2027

   Dalawang bagay ang nangyari sa autonomous na offensive security sa iisang Lunes, at magkasalungat ang tinuturo ng dalawa. Inanunsyo ng Horizon3 ang isang 250 milyong dolyar na Series E sa balwasyong lampas dalawang bilyon, humigit-kumulang triple ng 650 milyong dolyar na balwasyong dala nito palabas ng Series D noong Hunyo 2025, na magkasamang pinamunuan ng NightDragon at NEA, na parehong shareholder na, at sapat ang labis na demand para tumanggap ng pitong bagong mamumuhunan kasabay ng limang bumalik. Kumuha ng upuan sa board si Dave DeWalt, tagapagtatag ng NightDragon, na namuno sa FireEye at McAfee bago nito. Nagbebenta ang kompanya ng isang autonomous na plataporma ng penetration testing, sabi nito na malapit na itong umabot sa 100 milyong dolyar na taunang paulit-ulit na kita noong nakaraang taon sa 120 porsiyentong paglago, at ang piniling pitch nito para sa pondo ay ito: awtomatiko na ngayon ang parehong opensa at depensa, at naghahabulan ang dalawa. Sa parehong araw, binuksan ng Microsoft ang Project Perception sa public preview sa loob ng Defender: mga red agent na nagmamapa ng daan patungo sa pagkakompromiso bago pa ito lakarin ng isang umaatake, mga blue agent na nagpapasya kung ano ang tunay na mahalagang panganib, at mga green agent na kumikilos upang itama ang mga ito. Kusa silang naghahabilinan sa isa't isa sa halip na pumila para sa isang tao sa pagitan ng mga yugto, at nakapresyo ito ayon sa konsumo. Ang isang kompanya ay katatapos lamang presyuhan bilang isang buong kategorya. Ang isa naman ay katatanaw lamang sa pagdating ng kakayahang iyon bilang isa pang metro sa isang bill na binabayaran na ng mga kostumer nito.
   
   Ang agarang basa rito ay pinababa ng ikalawang pangyayari ang presyo ng una bago pa matuyo ang tinta, at maling lugar iyon para tumingin. Sa halip, itanong kung ano ang binibili ng isang kostumer kapag bumibili ito ng penetration test na hindi naman nito ginustong bilhin. Malaking bahagi ng gastos na iyon ay umiiral dahil hinihingi ito ng isang pamantayan, at hindi kakayahan ang hinihingi ng mga pamantayan. Humihingi ang pamantayan sa seguridad ng datos ng payment card ng isang tester na kwalipikado at hiwalay sa organisasyon, at pinapangalanan nito ang mga kredensyal na nagpapakwalipika sa isa. Humihingi naman ang pederal na programa ng awtorisasyon sa cloud sa Estados Unidos ng isang assessor na akreditado upang gawin ang pagtatasa. Wala sa dalawa ang nagtatanong kung gaano katalino ang tooling. Ang binibili ay ang pirma ng isang taong mananagot sa isang dokumentong tatanggapin ng isang auditor, at matagal nang inamin ito ng Horizon3 bago pa ang araw na ito. Ang sarili nitong alok sa pagsunod sa pamantayan ng payment card ay inihahatid ng mga Offensive Security Certified Professional ng Horizon3 — mga taong tester na nag-aabot sa kostumer ng ulat ng penetration test at ng kasamang ulat ng aksyong pang-ayos na maibabahagi sa napiling auditor, habang tumatakbo sa ilalim nila ang autonomous na plataporma. Ang pinaka-autonomous na kompanya sa kategorya ay may nakalagay nang sertipikadong tao sa invoice para sa bahaging kailangang pirmahan.
   
   Anim na araw bago ang pondo, tumigil ang ganoong ayos sa pagiging improbisasyon at naging pamantayan. Noong Hulyo 28, inilathala ng CREST — ang katawang nag-aakredita sa mga kompanya ng penetration testing — ang unang mga dagdag na AI sa mga pamantayan nito sa akreditasyon, at binuksan nito ang aplikasyon sa parehong araw. May bagong Domain 7, Responsible AI Use, sa pangkalahatang kinakailangan ng kompanya, na sumasaklaw sa pamamahala, pangangasiwa at transparency sa paggamit ng AI ng isang provider bilang organisasyon. May bagong Annex B rin, AI-Enabled Penetration Testing, sa pamantayan ng akreditasyon sa penetration testing, na nakasulat upang pinatitibay ng AI ang propesyonal na paghuhusga at hindi pinapalitan ito. Wala pang may hawak nito, at inaasahan ng CREST ang unang akreditadong organisasyon sa loob ng mga isang buwan. Ito ang ginagawa ng dokumentong iyon: ang iisang bagay na hindi kayang ibigay ng isang naka-bundle na produkto ay nagiging isang bagay na maisusulat ng bumibili sa isang purchase order — nasuri nang nakahiwalay, hawak ng isang pinangalanang kompanya, at tungkol sa paraan ng pagsasagawa ng engagement sa halip na sa lakas ng tooling. Ito ang unang artefact sa tahing ito na hindi paghahabol sa kakayahan at hindi rin iskor sa benchmark.
   
   Ang hula ay pipila ang mga kompanya ng plataporma. Pagsapit ng katapusan ng Q2 2027, may hindi bababa sa isang kompanyang pinondohan ng venture capital, na ang ibinebentang pangunahing produkto ay isang autonomous o AI-driven na plataporma ng penetration testing — malinaw na kandidato ang Horizon3 at hindi lamang ito — na may hawak na akreditasyon sa ilalim ng bagong mga pamantayang AI ng CREST, at lumalabas ito bilang ganoon sa mismong listahan ng akreditasyon ng CREST. Apat na bagay ang hindi binibilang. Hindi binibilang ang pangkalahatang akreditasyon ng CREST sa penetration testing na hawak nang walang bagong dagdag na AI, dahil mas nauna pa ito kaysa sa tanong. Hindi binibilang ang isang tradisyonal na konsultansiyang nagbebenta ng engagement na ginagawa ng tao at nagpatibay ng daloy ng trabahong tinutulungan ng AI, dahil iyon mismo ang sektor na pinagsulatan ng pamantayan at walang naaayos ang akreditasyon nito tungkol sa mga kompanya ng plataporma. Hindi binibilang ang isang blog post na naghahabol ng pagkakatugma sa pamantayan, isang dokumento ng control mapping, o isang pirma sa isang boluntaryong kodigo, dahil ang nakahiwalay na pagtatasa ang buong punto ng bagay na ito. At hindi binibilang ang akreditasyong hawak ng isang service partner, reseller o delivery affiliate sa halip na ng mismong kompanya ng plataporma, dahil ang pagruta ng pirma sa iba ang mismong kabilang kalalabasang ipinagbabawal nito.
   
   Ang pinakamalakas na tutol ay ito: mga service provider ang inaakredita ng CREST, at hindi isa roon ang isang kompanyang nagbebenta ng software subscription, kaya maaaring hindi lamang talaga bagay ang akreditasyon sa korporasyong pinapahalagahan sa dalawang bilyong dolyar. Ang pangalawa ay heograpiya. Pinakamalakas ang hatak ng CREST sa United Kingdom, sa Gulf at sa Singapore, at makatuwirang magpasya ang isang vendor na nakabase sa US at nagbebenta sa malalaking negosyong US na sapat na ang sarili nitong sertipikadong tauhan at ang mga auditor ng mga kostumer nito. Ang pangatlo ay ang orasan: isang linggo pa lamang ang pamantayan, hindi mabilis ang isang pagtatasa, at mga apat na quarter na lamang ang natitira sa bintana kapag nagpasya nang kumilos ang isang kompanya. Ang pang-apat ang pinaka-interesante: salungat ito sa kuwentong pinagpresyuhan ng pondo. Ang isang kompanyang katatapos lamang mangalap ng 250 milyong dolyar sa pangangatwirang awtomatiko na ang parehong opensa at depensa, at umuusad mula sa paghahanap ng kahinaan tungo sa pag-aayos nito nang walang taong nasa loob ng proseso, ay hindi malinaw na gugustuhing ipagsigawan ang isang pamantayang ang pundasyon ay nananatiling mananagot ang isang kwalipikadong tao mula simula hanggang dulo. Ang salungat naman dito ay kung sino ang nakatayo sa kabilang panig ng palitan. Sinusuri ng mga red agent ng Microsoft ang sariling ari-arian ng kostumer mula sa loob nito, walang anumang paghahabol sa pagsunod ang product page nito, at hindi isasakay ng isang vendor ng plataporma sa sariling papel nito ang pananagutan ng isang pinatunayang opensibong engagement. Ibebenta nito ang metro at iiwan sa mga partner ang pirma. Kaya ang pirma ang natitirang bahagi ng kategoryang ito na hindi maaabot ng isang bundle sa mismong istruktura nito, at ang kompanyang katatapos lamang mag-triple ng balwasyon ay may 250 milyong dolyar na maipambibili nito.

   In plain language: Kukuha pa rin ng sertipikong pinatatakbo ng tao ang mga kompanyang nagbebenta ng awtomatikong kagamitan sa panghahack, dahil tanging ang pagsusuring pangseguridad na pinirmahan ng kwalipikadong tao ang tinatanggap ng mga auditor.


3. Magkakaroon ng malayang sinukat na bilang sa serving ang mga accelerator stack na isinulat ng agent pagsapit ng Q2 2027

   Ayon kay Jeremy Nixon, na umalis sa Google Brain upang itatag ang Infinity noong isang taon, itinutok ng koponan niya ang mga AI coding agent sa silikon ng d-Matrix at nagkaroon ng tumatakbong software na katumbas ng CUDA sa loob ng mga sampung oras, na umabot sa mga 92 porsiyento ng teoretikal na rurok ng bahaging Corsair sa tensor-parallel na matrix multiplication. Sa loob ng sampung araw, sabi niya, tatlong frontier na modelo ang tumatakbo nang buong-buo sa chip, at bawat layer ay isinulat mula sa wala. Ang agent na sumusulat, ang Ignition, ang gumagawa, sumusubok at nagtutunong ng mga compute kernel na nagtatakda kung gaano kabisa tumakbo ang isang modelo sa isang accelerator — sa kasaysayan, ito ang trabahong nagkakahalaga sa isang humahamong vendor ng isang espesyalistang koponan at ilang taon, at ito ang dahilan kung bakit halos hindi nangyayari ang porting. Isinara ng Infinity ang isang 15 milyong dolyar na seed sa 100 milyong balwasyon noong isang buwan.
   
   Galing sa unang partido ang bawat bilang sa salaysay na iyon, at hindi magkapareho ang dalawang paghahabol sa loob nito. Ang siyamnapu't dalawang porsiyento ng teoretikal na rurok ay isang ratio laban sa aritmetikang kaya sanang ilabas ng silikon, sinukat sa iisang uri ng kernel, sa isang hugis at isang precision na mismong pinili ng sumulat ng kernel, at nasa tamang lugar na ang datos. Tunay na resulta iyon sa inhinyeriya, at siya ring pinakanakabibighaning bilang na makukuha sa isang bagong bahagi. Ibang sukat at mas mahirap ang end-to-end na serving: isang pinangalanang modelo sa nakasaad na precision, batch size at haba ng konteksto, na may dalang attention, trapiko ng key-value cache, sampling, at ang mahabang buntot ng mga operator na hindi kailanman nagagalaw ng isang benchmark ng matrix multiply. Puwedeng malapit sa rurok ang isang stack sa kernel na pinakamahalaga at talo pa rin ito sa token kada segundo, dahil ang mga operator na walang sumukat ang siyang humihinto. Ang mas malakas na paghahabol ni Nixon — tatlong modelong tumatakbo nang buong-buo sa loob ng sampung araw — ang siyang mag-aayos sana sa pagtatalo, at dumating ito nang walang katabing bilang ng throughput.
   
   Dala rin ng parehong ikot ng balita ang hindi pagkakasundo kung nasaan na ngayon ang moat. Sabi ni Marshall Choy ng Rebellions, hindi na salik ang CUDA sa inference. Binabasa naman ni Chris Lattner ng Modular ang minanang graphics ng CUDA bilang isang pasaning hindi nito maiaalis. Kabaligtaran ang itinuturo ni Daniel Newman ng Futurum: ang pagbili ng NVIDIA sa SchedMD noong Disyembre, na siyang nagmamantini sa Slurm scheduler, at ang argumento niya ay umakyat lamang ang moat sa stack sa halip na maubos ito. Hindi ito naaayos ng pagtatalo. Ang aayos nito ay kung makakahanap ang isang sumusuri sa isang humahamong bahagi ng isang bilang sa serving na hindi niya kailangang kunin mismo sa nagbebenta.
   
   Kaya nakatuon ang hula sa kung sino ang naglalathala, hindi sa kung sino ang tama. Pagsapit ng katapusan ng Q2 2027, may isang artefact na mababasa ng publiko na nag-uulat ng end-to-end na throughput o latency ng inference para sa isang pinangalanang modelong tumatakbo sa isang pinangalanang accelerator na hindi NVIDIA, na nakasaad na makina ang gumawa ng kernel o compiler layer nito, at inilalantad nito ang konpigurasyon ng takbo — modelo, precision, batch size o concurrency, at haba ng sequence — nang sapat na malinaw upang masubukan ng isang mambabasa ang parehong takbo. Walang komersyal na interes ang naglathala sa silikon at maging sa code generator: isang akademikong grupo, isang nakahiwalay na katawang tagasuri, o isang kostumer na nag-uulat ng sarili nitong sukat. Isang edge case ang naaayos nang maaga sa halip na pagkatapos: binibilang ang isang resultang dala sa isang round ng MLCommons Inference kahit na ang nagsumite mismo ang nagpapatakbo ng hardware, dahil sa konsorsiyo at hindi sa nagsumite nabibilang ang mga kinakailangan sa paglalantad at ang pagsusuri. Walang kinalaman sa pamantayan kung paano ginawa ang stack: kasinghalaga lamang ang isang agent na naglalabas ng Triton o MLIR ng isang agent na naglalabas ng mga kernel na hinubog ng kamay, basta nakasaad sa paglalathala na makina ang sumulat ng layer.
   
   Nagiging mali ito kung walang artefact na tumutugon sa lahat ng kondisyong iyon ang pampubliko sa 30 Hunyo 2027, at tatlong pangkaraniwang paraan ang puwedeng magdulot nito. Ang partidong pinakanakalalamang para isagawa ang sukat ay ang mismong nagbebenta ng bahagi, at karaniwang dumarating ang mga nakahiwalay na tagasuri matapos magkaroon ng mga bumibili at hindi bago pa ito, kaya puwedeng blog ng vendor, press release, keynote slide at panayam sa tagapagtatag pa rin ang buong korpus, gaano man kadetalyado ang mga iyon. May sariling bigat ang porsiyento-ng-rurok — mura ito, nakabibighani ito, at ito ang kayang gawin ng isang kompanyang nasa seed stage sa loob ng isang linggo — kaya puwedeng ang microbenchmark pa rin ang manatiling bilang na sinisipi ng lahat. Karapat-dapat pangalanan ang pangatlong daan dahil hindi ito pagkatalo para sa saligang tesis: puwedeng manatili ang larangan sa saklaw ng operator bilang tapat na sukatan — ibig sabihin, kung gaano karami sa mga bahagi ng isang framework ang talagang naipapatupad ng isang ginawang stack — at iulat iyon kapalit ng throughput. Kung iyon ang mangyari at walang bilang sa serving na lumitaw mula sa isang naglathalang walang kaugnayan, mali pa rin ang kalalabasan nito.

   In plain language: Sabi ng isang start-up, sampung oras lamang isinulat ng AI ang software ng isang chip. Kailangan itong sukatin ng isang walang interes bago ito mabilang.
