## Future


1. Magiging pangunahing primitive ng mga frontier API ang subagent orchestration pagsapit ng Q1 2027

   Higit pa sa pagpapahaba ng hagdan ng presyo ang malawakang rollout ng GPT-5.6: kasama sa Sol ang max reasoning effort setting at isang ultra mode na naghahati ng kumplikadong trabaho sa mga subagent. Ibig sabihin, itinuturing na ng flagship na product path ang multi-agent na paghahati ng trabaho bilang built-in na paraan ng pagpapatakbo, hindi bilang bagay na kailangan pang i-wire ng mga developer gamit ang mga framework. Ipinapakita ng mga release ng parehong linggo na buong industriya ang hila: ang Muse Spark 1.1 ng Meta ay tahasang ginawa para sa agentic na trabaho at nangunguna sa mga scaled tool-use benchmark tulad ng MCP Atlas, at ang MDASH harness ng Microsoft ay nag-o-orchestrate ng mahigit 100 espesyalisadong agent sa mga frontier at distilled na model sa production para maghanap ng mga Windows vulnerability. Lumilipat ang capability frontier mula sa lalim ng reasoning ng iisang model patungo sa orchestrated na paghahati ng trabaho: pagruruta ng mga subtask sa mas murang distilled na tier, pagdedebate sa mga pansamantalang resulta, at pagsasama-sama ng mga ito. Ang prediksyon: pagsapit ng Q1 2027, hindi bababa sa dalawang frontier API provider ang maglalabas ng server-side na subagent orchestration bilang dokumentado at sinisingil na API primitive — isang kontrol sa antas ng request (tulad ng ultra mode) kung saan ang provider mismo ang nagpapasimula, nag-iiskedyul, at sumusukat ng singil sa mga child agent, na may presyong pinaghahalo ang mga tier (mga Sol-class na planner na nagdedelegang trabaho sa mga Luna-class na worker). Kapag nasa likod na ng API ang orchestration, lilipat ang kompetisyon sa benchmark at presyo mula sa kalidad ng model kada token patungo sa orchestrated na throughput kada task, at ang mga mid-tier na model tulad ng Terra at Muse Spark ang magiging mga workhorse sa loob ng fan-out ng ibang model.


   In plain language: Malapit nang magbenta ang mga AI company ng button na awtomatikong hinahati ng isang matalinong model ang malaking trabaho sa mas murang mga katulong na model.


2. Bababa sa ilalim ng $1 kada milyong input token ang presyo ng mid-tier na frontier API pagsapit ng Q2 2027

   Sa loob ng iisang linggo, nadagdagan ng ikaapat na agresibong nagbebenta ang frontier-model na API market at nawala ang unan nito sa presyo. Sa paglulunsad ng Muse Spark 1.1, inilagay ng Meta sa public preview ang may presyong Meta Model API sa $1.25 kada milyong input token at $4.25 sa output — mas mababa sa bawat karibal na flagship tier — habang inilagay ng GPT-5.6 ladder ng OpenAI ang Terra sa $2.50/$15 bilang GPT-5.5-class na performance sa halos kalahati ng dating gastos, na tahasang nagre-reset ng mid-tier na cost floor na pinagbabatayan ng presyo ng mga karibal. Dahil sa estruktural na posisyon ng Meta, magiging matagalang price war ito sa halip na panandaliang promo: taun-taon nitong kinita ang AI sa pamamagitan ng ads at kaya nitong ituring na opsyonal ang margin ng API, kaya mapipilitan ang OpenAI, Anthropic, at Google na ipagtanggol ang bahagi nila sa agentic-workload segment na direktang tinatarget ng Muse Spark gamit ang mga iskor nito sa MCP Atlas at JobBench. Ang prediksyon: pagsapit ng Q2 2027, hindi bababa sa dalawa sa apat na malalaking frontier vendor ang mag-aalok ng mid-tier na model — GPT-5.5-class o mas mahusay pa ang kakayahan, hindi maliit na distilled na tier — sa presyong mas mababa sa $1 kada milyong input token, na may proporsyonal ding pagbaba sa presyo ng output. Diretso ang mekanismo: tugon sa kompetisyon — ang mid-tier ng bawat vendor ang volume workhorse para sa summarization, automation, at mga agent-orchestration pipeline, at ito ang pinaka-sensitibo sa presyo na segment; kapag na-angkla na ng Meta ang inaasahan sa $1.25 sa preview, itutulak ng general availability at ng unang round ng pagtapat sa presyo ang floor pababa sa $1.


   In plain language: Nasa price war ang mga AI company, kaya dapat maging mas mura nang malaki ang pagrenta ng malakas na mid-range na AI model sa loob ng isang taon.


3. Maglalabas ng agentic vulnerability scanning ang pangalawang malaking vendor pagsapit ng Q1 2027

   Ang anunsyo ng Microsoft noong July 9 na inililipat ang MDASH — ang multi-model harness nito na nag-o-orchestrate ng mahigit 100 espesyalisadong AI agent para tuklasin, pagdebatehan, at patunayang exploitable ang mga bug — sa dedikadong cloud infrastructure na nakasukat para sa Windows-scale na pag-scan ay kauna-unahang pagkakataon na inilagay ng isang OS vendor sa production ang agentic na pagtuklas ng vulnerability. May kongkreto nang resulta ang harness: 16 na bagong vulnerability sa networking at authentication stack, kabilang ang apat na kritikal na remote-code-execution na depekto sa kernel TCP/IP stack at sa IKEv2 service. Ang prediksyon: sa loob ng susunod na dalawa hanggang tatlong quarter, hindi bababa sa isa pang malaking OS o hyperscale cloud vendor (Google, Apple, Amazon, o isang tagapangalaga ng Linux ecosystem tulad ng Red Hat/SUSE na suportado ng hyperscaler) ang mag-aanunsyo ng sarili nitong production-scale na agentic scanning harness para sa isang flagship codebase, at hindi bababa sa isa sa mga programang ito ang hayagang mag-uugnay ng mga natuklasan nito sa off-calendar at risk-driven na patch release sa halip na sa nakatakdang buwanang siklo. Tatlong puwersa ang nagpapahirap iwasan ito. Una, tahasang sinabi ng Microsoft na simetriko ang AI-speed na pagtuklas — gumagana rin ang parehong kakayahan para sa mga umaatake, punto na binigyang-diin ng JADEPUFFER na insidente kung saan isang autonomous na agent ang nagpatakbo ng buong intrusion mula simula hanggang dulo — kaya ang vendor na hindi nag-i-scan ng sariling code sa bilis ng makina ay isinusuko ang unang pagtuklas sa mga kalaban. Pangalawa, commodity na ang mga sangkap: sa parehong linggo, inilabas ng OpenAI ang GPT-5.6 na may subagent-driven na ultra mode at binuksan ng Meta ang Muse Spark API nito na may nangungunang tool-use na iskor. Ibig sabihin, ang multi-agent orchestration layer na kinakatawan ng MDASH ay maaari nang gayahin gamit ang mga inuupahang frontier model, hindi na kailangan ng sariling research program. Pangatlo, ang pampublikong argumento ng Microsoft na dapat mapalitan ang mga patch cycle na nakatali sa kalendaryo ng tuloy-tuloy at risk-driven na remediation ay lumilikha ng presyon mula sa kompetisyon at regulasyon sa mga kapantay nito na magpakita ng katumbas na kakayahan. Ang landing zone pagsapit ng Q1 2027: anunsyo ng pangalawang vendor ng production na agentic scanning program, may inihayag na bilang ng CVE, at ang mga unang nakikitang lamat sa nakapirming patch-Tuesday-style na ritmo sa alinmang vendor na nagpapatakbo ng ganitong mga harness.


   In plain language: Gumagamit na ang Microsoft ng kawan ng mga AI agent para hanapin ang sarili nitong mga security bug; gagayahin ito ng ibang malalaking software maker sa loob ng ilang buwan.
