3. Tatanggihan ng mga self-hosted na AI tool ang malayuang pag-bind na walang authentication pagsapit ng H1 2027

   Inilalarawan ng XLab ng QiAnXin ang NadMesh bilang isang scanner na nag-eenumera ng self-hosted na AI infrastructure ayon sa port — ComfyUI, Ollama, n8n, Open WebUI, Langflow at Gradio sa 8188, 11434, 7860 at 5678 — at credential ang kinukuha nito, hindi compute: mga cloud key mula sa environment variable, Kubernetes service-account token, at ang laman ng ~/.aws/config at .env. Hayagang pinagdududahan ng XLab ang sariling kabuuang bilang ng operator, ngunit nananatili ang listahan ng target. Ang gumagawa nitong istruktural ay kung sinong kasama ngayon ng AI stack sa distribusyon ng inisyal na access: remote code execution sa Docker API sa 30.31%, script-console execution sa Jenkins sa 22.28%, mahihinang telnet password sa 10.36%, at Redis sa 8.29%. Iyan ang klasikong grupo ng misconfiguration, at ang presensya ng Redis ang kapaki-pakinabang na detalye, dahil dumaan na ang Redis sa mismong pagwawasto na hinuhulaan dito. Ang malawakang pag-scan sa mga nakalantad na instance ang nagbunga ng protected mode, na tumatangging paglingkuran ang mga remote client kapag walang nakatakdang password. Inilipat ng MongoDB ang bind address nito sa loopback matapos ang sarili nitong alon ng ransom. Ginawang sapilitang bahagi ng production check ng Elasticsearch ang isang na-rutang bind. Hindi pa dumaraan ang mga AI tool sa ikot na iyon. Ilan sa kanila ay naka-bind na sa loopback, ngunit sa wala ni isa sa kanila ang credential ang nagbabantay sa paglalantad. Iisang flag o environment variable ang naglalagay sa serbisyo sa isang network, at hiwalay na setting — na walang obligadong galawin — kung may nag-a-authenticate man. Kaya nga perimeter hygiene ang inaalok na payo sa halip na pagpapatupad ng software. Ang hula ay magsisimula nang ipatupad ito ng software mismo. Pagsapit ng H1 2027, kahit dalawa sa ComfyUI, Ollama, Open WebUI, Langflow, n8n at Gradio ang maglalabas ng release kung saan tinatanggihan, ibinababa pabalik sa loopback, o hinaharangan ng tahasang pagkilala ang pag-bind sa isang non-loopback na interface nang walang authentication credential. Nakadokumento ito bilang breaking na pagbabago sa default sa release notes, hindi inaalok bilang opsyonal na gabay sa hardening. Ang komersyal na dimensyon ang nagtatakda ng iskedyul. May mga pondadong kompanya at produktong pag-aari ng korporasyon na ngayon sa likod ng mga proyektong ito, at ang isang pinangalanang puwesto sa listahan ng target ng isang botnet ay hadlang sa procurement, hindi isang thread sa support forum. Isinasara ito ng failure mode na idinokumento ng XLab. Ang isang workstation na nagpapatakbo ng local inference katabi ng isang matagal nang cloud credential file ay daan para sa lateral movement papasok sa account na nagmamay-ari nito, at ang ipinadalang default ang tanging kontrol na umaabot sa mga operator na hindi kailanman nagbabasa ng gabay sa hardening.


   In plain language: May botnet na naghahanap sa mga AI server sa bahay para sa mga cloud password, kaya malapit nang tumanggi ang mga tool na ito na mag-online nang walang login.
