1. Magkakaroon ng pinangalanang haba ng context ang under-2.5 GB na claim ng LFM2.5-2.6B pagsapit ng Q3 2027

   Inilathala ng Liquid AI ang LFM2.5-2.6B noong Martes, Agosto 4: 2.6 bilyong parameter, pre-trained sa humigit-kumulang 34 trilyong token, na pinalawig ang context window nito sa 128K noong kalagitnaan ng training, at nakatutok mismo sa gawaing agent — pagpaplano, tool call, mga gawaing maraming hakbang — na natatapos sa mismong device sa halip na bumalik-balik sa isang hosted service. Tatlong bilang ang bumubuhat sa alok. Wala pang 2.5 GB na memory ang footprint. 128K ang context window. 77.83 ang iskor sa paggamit ng tool sa ToolSandbox, laban sa 65.00 ng Gemma 4 E4B-it at sa 52.40 ng Gemma 4 E2B-it. Sa paglabas, sakop ng runtime support ang llama.cpp, MLX, vLLM, SGLang at ONNX, sa transformers 5.0.0 o mas bago. Sa vendor mismo nanggaling ang bawat isa sa mga bilang na iyon, inilathala kasabay ng modelo at hindi malayang inulit ng iba, at iyon ang caveat na ilalapat ng karamihan sa mga bumabasa.
   
   Hindi iyon ang kawili-wiling caveat. Ito ang kawili-wili: dalawa sa tatlong bilang na iyon ay naglalarawan sa magkaibang estado ng parehong proseso, at hindi kailanman sinasabi ng release ang dalawa nang magkasama. Ang wala pang 2.5 GB ay bilang tungkol sa modelo. Ang 128K ay bilang tungkol sa kung gaano karami sa isang session ang kayang hawakan ng modelo. Ang isang tool-calling agent loop ang lugar kung saan nagtatagpo ang dalawa, at hindi sinasabi ng release kung saan iyon. Ang isang loop na tumatakbo nang sapat katagal para tawaging agent ay nakaipon na ng output ng tool, ng mga pansamantalang plano at ng sarili nitong transcript, at ang halaga ng pag-ipong iyon ang nagpapasya kung nananatili pa ang loop sa memory sa huling bahagi ng isang session at hindi lang sa simula nito. Walang inilathala kasabay ng modelo na nagsasabi kung ano ang halaga nito sa 8K, o sa 32K, o sa 128K na ipinagmamalaki nito. Sinasabi nitong wala pang 2.5 GB, at hiwalay nitong sinasabing 128K, at naiiwan sa bumabasa ang pagpapalagay na kaya ng una ang ikalawa.
   
   Mas mabigat dito ang butas na iyon kaysa sa isang hosted na modelo, dahil isang hangganan sa hardware ang buong argumento ng release na ito. Ang sariling sukat ng kompanya sa mga device — 220 token kada segundo sa isang Apple M5 Max, 113 token kada segundo sa isang AMD Ryzen AI Max+ 395 — ay throughput, at hindi footprint ang throughput. Ang bilang na malapit sa 15,000 output token kada segundo sa iisang NVIDIA H100 sa mataas na concurrency ay bilang pang-server at sumasagot naman sa ibang tanong tungkol sa pag-deploy. Ang developer na nagpapasya kung kasya ang isang agent sa isang laptop, sa isang handset o sa isang embedded board ay hindi nagtatanong kung gaano ito kabilis. Ang tinatanong niya ay kung ano ang hawak nito kapag malalim na ang session, sa hardware kung saan ang pagkaubos ay isang crash at hindi isang autoscale. Ang hangganan sa memory ang bilang na piniling ipangunahin ng release na ito, at ito rin ang bilang na pinakakaunti ang paglilinaw.
   
   Itinatakda ng hula na magkakaroon ng haba ng context ang hangganan. Pagsapit ng katapusan ng Q3 2027, isasaad ng sariling inilathalang materyal ng Liquid AI para sa LFM2.5-2.6B — ang model card, ang dokumentasyon sa repository, o isang sumunod na post mula sa kompanya — ang isang bilang ng memory kasama ang haba ng context na doon ito humahawak. Naaayos ito ng isang talahanayang may bilang ng memory sa isang hanay at haba ng context sa isa pa. Naaayos din ito ng isang nakasaad na peak-memory para sa isang session na pinatakbo sa isang pinangalanang haba. Hindi ang direksyon ng paggalaw ng bilang ang claim; ang mismong pagsasaad nito ang claim.
   
   May ilang mas mahihinang bagay na hindi binibilang, at sulit pangalanan ang bawat isa dahil iyon ang unang inaabot ng isang naglalathala sa ilalim ng ganitong presyon. Hindi binibilang ang pag-uulit ng bilang na walang paglilinaw, gaano man ito katanyag ang puwesto, dahil iyon na ang nangyari na. Hindi binibilang ang talahanayan ng laki ng file kada antas ng quantisation, dahil hindi ang file sa disk ang hawak ng isang tumatakbong loop. Hindi binibilang mag-isa ang bilang ng token kada segundo na sinukat sa isang pinangalanang haba ng context, dahil walang sinasabi ang throughput sa isang haba tungkol sa footprint sa habang iyon. Hindi binibilang ang isang configuration file na mahihinuha ng bumabasa ang sagot, dahil ang tinutugunan ng isang claim tungkol sa pag-deploy sa device ay ang developer na pumipili sa mga modelo, hindi ang isang sapat nang nakatuon para basahin ang config. At hindi binibilang ang isang bilang na inilathala para sa ibang kasapi ng pamilya; ang sinusubok na claim ay ang nakakabit sa release na ito.
   
   Ang pinakamatibay na pagtutol ay walang presyon sa isang vendor na linawin ang isang headline na umuubra. Nahihinuha ito nang mag-isa ng mga praktisyoner na nagpapatakbo ng llama.cpp, at ang paghingi sa isang kompanyang ilathala ang bilang na nagpapapangit sa sarili nitong hangganan ay paghingi sa kaniyang tutulan ang sarili niyang paglulunsad. Arkitektural ang ikalawang pagtutol, at ito ang gagawing hindi lang basta hindi natupad kundi hindi na kailangan ang hulang ito: walang sinasabi ang release tungkol sa kung paano lumalaki ang memory ng modelong ito habang napupuno ang context, at kung napakapatag nitong lumaki ay mas malapit sa totoo ang hangganang walang paglilinaw kaysa sa hitsura nito at wala nang kailangang muling sabihin. Ang ikatlo ay napupunta ang atensyon kung nasaan ang kompetisyon, at ang kompetisyon dito ay ang talahanayan ng benchmark — ang 77.83 laban sa 65.00 at 52.40 ang paghahambing na sinasagot ng isang karibal, kaya mas malamang na iskor kaysa footprint ang susunod na mga bilang na ilalathala sa espasyong ito.
   
   Mas tahimik kaysa alinman doon ang matapat na paraan ng pagkabigo. Maaaring hindi na lang lumitaw ang bilang, hindi dahil pumapangit ito kundi dahil walang humingi nito, at mababasang mali ang isang hulang may bagay na mananatiling hindi nasasabi kapang ang totoong nangyari ay walang nangyari. Isa itong claim tungkol sa kung ano ang ipinapangako ng naglalathala sa nakasulat. Laban sa akin ang hatol ng katahimikan.

   In plain language: Ipinapalabas ang modelo sa wala pang 2.5 GB. Walang inilathalang bilang na nagsasabi kung ano ang kailangan nito habang aktuwal na tumatakbo ang isang gawaing agent.


2. Maglalathala ang Herdr ng bayad na tier sa itaas ng Apache-2.0 na runtime nito pagsapit ng Q2 2027

   Sinabi ng Herdr noong Huwebes, Agosto 6 na sumali ito sa F26 batch ng Y Combinator, at sa parehong post ay binago nito ang lisensya ng runtime nito mula AGPL patungong Apache-2.0. Ang Herdr ay isang terminal runtime para sa mga command-line coding agent: inaayos nito ang mga ito sa mga pane, tab at proyekto at pinananatiling tumatakbo ang mga ito nang tuloy-tuloy sa makinang kinaroroonan nila, at magkahiwalay sa isa't isa ang mga makinang iyon sa ngayon. Walang halaga ng pondo na lumilitaw kahit saan sa anunsyo, at hindi isang round ang pagpasok sa isang batch, kaya walang bilang na nakakabit dito at wala ring dapat hinuhain. Ang isinasaad ng post ay isang hati. Mananatiling libre sa ilalim ng Apache-2.0 ang runtime na ginagamit ng mga tao ngayon, at itatayo sa itaas nito ang mga komersyal na tampok, kung saan pinangalanan bilang dalawang kandidato ang multi-machine connectivity at ang mga client na labas sa terminal interface.
   
   Ang linya tungkol sa lisensya ang may pinakamabigat na bunga, at sulit maging eksakto tungkol sa kung ano ang gumalaw. Ang network-use clause ng AGPL ang siyang mag-oobliga sa isang hosted service na nakatayo sa Herdr na ilathala ang sariling source nito; inaalis ng Apache-2.0 ang obligasyong iyon. Mula sa labas, mababasa iyon bilang pagbabago sa pag-ampon — nagagawa na ngayon ng isang kompanyang hindi dati makapaglagay ng AGPL na runtime sa likod ng sarili nitong serbisyo. Mula sa loob, kabaligtaran ito ng isang panangga. Ang clause na katatanggal lang ang tanging bagay sa stack na nagreserba sa hosted layer para sa mga taong sumulat ng runtime, at ang pagsuko nito ay nag-iiwan sa layer na iyon na walang nagrereserba maliban sa pagiging una at pagiging mas mahusay. Ang kompanyang nag-aalis ng legal na hawak nito sa layer na sinabi nitong balak ipagbili ay may dahilan para gawing isang produktong may presyo ang layer na iyon sa halip na isang nakasaad na plano, dahil hindi na hawak ng lisensya ang puwesto para dito.
   
   Ang parehong linggo ang naghahatid ng presyon mula sa kabilang panig. Inilathala ng research group ng Meta ang Muse Code noong Miyerkules, Agosto 5, isang terminal coding agent na hayagang nasa beta, na ang mga subagent ay nananatili sa buong session sa halip na buuin isa-isa kada gawain at na ang bawat tawag sa modelo, pagpapatakbo ng tool, pag-apruba at pag-edit ay idinadagdag sa isang lokal na event log na nagpapagawa sa isang run na replay-exact at restart-safe. Ang pananatili sa isang session at ang pagtagal sa isang restart ay ang parehong mga bagay na ipinapangako ng runtime ng Herdr, at walang pinapangalanang presyo ang anunsyo para sa alinman doon. Hindi nito ginagawang magkapalit ang dalawa — isang agent ang Muse Code, at ang Herdr ang runtime na loob nito tumatakbo ang ibang agent — ngunit ipinapakita nito kung saan naglalakbay ang kakayahan sa layer na ito kapag nagpasya nang maglabas ang isang malaking research group, at argumento ito laban sa mismong runtime na maging ang bagay na may dalang bayarin.
   
   Itinatakda ng hula na magiging bilang ang layunin. Pagsapit ng katapusan ng Q2 2027, maglalathala ang Herdr ng presyo para sa sarili nitong bayad na tier — isang plan o pricing page, o isang katumbas na inilathalang dokumentong nagsasaad kung magkano ang tier — at papangalanan ng paglalarawan sa tier na iyon ang kahit isa sa dalawang bagay na tinukoy ng post noong Agosto 6 bilang komersyal: ang koneksyon sa maraming makina, o isang client na labas sa terminal interface. Inaasahan at hindi komplikasyon ang pananatili ng runtime sa ilalim ng Apache-2.0 kasabay nito; iyon ang hating inilarawan ng post.
   
   May ilang halos-tumamang bagay na hindi binibilang, at bawat isa ay ang unang inaabot ng isang kompanya sa yugtong ito. Hindi binibilang ang isang waitlist, isang early-access form o isang coming-soon banner, dahil tungkol sa isang inilathalang presyo ang claim at hindi tungkol sa isang inilathalang layunin. Hindi binibilang ang muling pagsasabi ng planong Agosto 6 sa isang susunod na post, sa parehong dahilan. Hindi binibilang ang isang sponsorship o donation button: paraan iyon ng pagbabayad sa mga tagapagpanatili, hindi isang presyo sa isang layer. Hindi binibilang ang isang enterprise page na nag-aanyaya sa bumabasang makipag-ugnayan sa sales nang walang dalang halaga. Hindi binibilang ang isang libreng hosted service hangga't wala itong presyo, gaano man kalinaw na ito ang magiging bayad na bagay. At hindi binibilang sa alinmang direksyon ang isang anunsyo ng pondo — hindi presyo ang isang round, at hindi round ang pagpasok sa batch na nagbunsod nito.
   
   May dalawang pagtutol na sulit sabihin nang malinaw. Ang una ay walang nagtatakda ng orasan sa pinagkunan. Pinangalanan ng post ang mga komersyal na kandidato, hindi ito nagbigay ng petsa para sa mga ito at ng halaga para sa anuman, at ang isang maliit na koponang kapapalawak lang ng lisensya nito ay may mas magandang dahilan sa malapit na panahon para palaguin ang mga install kaysa singilin ang mga ito. Estruktural at hindi nakaiskedyul ang presyong ipinagtatalo dito, at kayang sipsipin nang matagal ang isang estruktural na presyon. Ang ikalawa ay nakababayad na ang relicence sa sarili nito kahit wala ang lahat ng ito: agad na pinalalawak ng Apache-2.0 kung sino ang makakagamit ng runtime, at kayang umupo nang walang katapusan ang isang proyekto na permissive ang lisensya at walang pinagkakakitaan. Marami ang ganoon.
   
   Mas tahimik kaysa sa alinmang pagtutol ang matapat na paraan ng pagkabigo. Maaaring dumating ang bayad na layer na nakabalot sa loob ng isang hosted na produktong may sariling pangalan, na binabayaran bilang isang buo at hindi bilang isang tier na nakaupo sa itaas ng runtime, at sa gayon ay walang makikitang pricing page sa tabi ng isang licence file ang bumabasa at tatawagin niya itong mali gayong tama ito. Tungkol sa isang presyong lumilitaw sa layer sa itaas ng runtime ang claim, hindi tungkol sa hugis ng pahinang kinalalabasan nito.

   In plain language: Ginawa lang ng Herdr na libreng gamitin ninuman ang pangunahing tool nito, kaya sa mga bayad na dagdag na kailangang manggaling ang pera.


3. Tatanggihan ng mga terminal coding agent ang mga command na inaprubahan ng operator pagsapit ng H1 2027

   Naglathala si Alex Wauters ng isang pagsusuri sa blog ng Scale X noong Miyerkules, Agosto 5 tungkol sa isang interactive na browser game kung saan ang manlalaro ang kumakatawan sa taong nag-aapruba para sa isang coding agent, tumatanggap o tumatanggi sa bawat command sa ilalim ng pressure ng oras. Sa mahigit 40,000 run at humigit-kumulang 409,000 pasyang aprubahan-o-tanggihan, 66.3% ang katamtamang katumpakan. Hindi ang katamtaman ang kawili-wiling bahagi; ang hugis nito ang kawili-wili. Umakyat ang miss rate kasabay ng layo ng isang mapaminsalang command mula sa bagay na sinanay katakutan ng mga tao: 11.7% sa mga command na halatang mapanira, 23.8% sa mga persistent mutation attack, 33.4% sa exfiltration at pagpapatakbo ng code, at 35.0% sa mga scope violation. Nahuli ng 35.2% ng mga manlalaro ang bawat banta, ngunit 20.8% lang ang nakagawa niyon habang hindi hihigit sa isa sa bawat limang ligtas na command ang hinarang nila; inaprubahan ng 7% ang lahat ng inilagay sa harap nila, at 32.9% ng mga session ang nagtapos sa negatibong iskor. Ang pinakamadalas na nalusutang command ay ang npm run analyze, na pinayagang dumaan sa 64.7% ng mga pagkakataon kahit na nakikita sa history log ang mapaminsalang payload.
   
   Hayagang sinasabi ng may-akda na artipisyal ang kalagayan — lumitaw ang mga banta sa 34% ng mga command, na mas mataas kaysa sa anumang tunay na trabaho, at hindi katumbas ng isang araw ng trabaho ang isang timed na laro — at may dalawang panig ang caveat na iyon, dahil mas bihira pang makatagpo ng mapaminsalang command ang isang tunay na operator at kaya mas hindi siya handa para dito. Ang nananatili matapos ang caveat ay hindi ang katamtaman kundi ang pagkakasunod-sunod, at pahayag ang pagkakasunod-sunod tungkol sa kung saan nakaupo ang impormasyon. Isang command line ang ipinapakita ng isang approval prompt. Ang sinusundan ng miss rate ay kung ano ang kinalalabasan ng linyang iyon, at para sa npm run analyze ay nakaupo iyon isang layer sa ibaba ng string na hinihingi sa manlalarong husgahan, sa isang log na hindi ipinapakita ng prompt. Hindi kayang suriin ng isang taong pinapaapruba ng isang pangalan ang isang payload. Hindi iyon kakulangan sa pagsasanay at hindi ito bumubuti sa isang mas malinaw na prompt.
   
   May dalawa pang bagay sa parehong siklo na naglalarawan sa layer na tinutulakan nito. Inilathala ng research group ng Meta ang Muse Code noong Miyerkules, Agosto 5 — isang terminal coding agent, hayagang nasa beta, na ini-install sa macOS at Linux sa pamamagitan ng pag-pipe ng install script mula sa dev.meta.ai — na nakatayo sa mga subagent na asynchronous, na nananatili sa buong session sa halip na buuin isa-isa kada gawain, at na sila mismo ang nagpapasya kung kailan mag-uulat pabalik sa pangunahing agent, na siyang nag-aalis ng round-trip na latency sa gawaing maraming hakbang. Idinadagdag sa isang lokal na event log ang bawat tawag sa modelo, pagpapatakbo ng tool, pag-apruba at pag-edit, na inilalarawan ng Meta bilang nagpapagawa sa agent na replay-exact at restart-safe. Malinaw na umiiral pa rin ang mga pag-apruba doon; itinatala ito ng log. Ang gumalaw ay ito: isang scheduler at hindi na ang taong iyon ang nagtatakda ng bilis ng pagdating ng mga command line sa harap ng iisang tao, at sinukat ng laro kung ano ang nangyayari sa katumpakan sa mismong kondisyong iyon. Ang Herdr, na naglalarawan sa terminal runtime nito noong Huwebes, Agosto 6, ang naghahatid ng kabilang kalahati: mga agent na inaayos sa mga pane, tab at proyekto at pinananatiling tumatakbo nang tuloy-tuloy sa makinang pinagpapatakbuhan sa kanila. Ang isang runtime na pananatili ang ipinagmamalaki ay isang runtime na halos lahat ng trabaho nito ay ginagawa habang walang nakatingin.
   
   Gastos ang matagal nang pagtutol sa paglipat ng tsek sa tool layer. Mura at marupok ang isang static na listahan ng tuntunin, at anumang tunay na bumabasa ng payload ay nangangailangan ng modelo sa likod nito. Gumalaw rin ang hadlang na iyon ngayong linggo. Inilathala ng Liquid AI ang LFM2.5-2.6B noong Martes, Agosto 4, isang modelong may 2.6 bilyong parameter na nakatutok sa pagpaplano, sa tool call at sa mga gawaing maraming hakbang na kasya sa wala pang 2.5 gigabyte na memory; inilalagay ito ng sariling sukat ng kompanya, na inilathala kasabay ng modelo at hindi malayang inulit ng iba, sa 220 token kada segundo sa isang Apple M5 Max at sa 77.83 sa ToolSandbox na benchmark para sa paggamit ng tool laban sa 65.00 ng Gemma 4 E4B-it. Ituring ang mga bilang na iyon bilang sa vendor, dahil iyon nga ang mga ito. Ang bahaging naililipat ay ang hangganan sa memory: ang isang screen na bumabasa kung ano ang kinalalabasan ng isang command ay hindi na nangangahulugan ng isang hosted service sa kabilang dulo nito. Hindi hinihingi ng hulang ito na maging modelo ang tsek, at kasingtama nitong nasasapatan iyon ng isang deterministikong policy engine. Mas makitid ang punto: naging mas mura nang alisin ang huling operasyonal na dahilan para iwan sa tao ang pasya.
   
   Itinatakda ng hula na hihinto sa pagiging sapat ang oo ng operator. Pagsapit ng katapusan ng H1 2027, maglalathala ang isang pinangalanang terminal coding agent o agent runtime ng isang release note, changelog entry o pahina ng dokumentasyon, na may petsang pagkatapos ng Agosto 6, 2026 at naglalarawan sa gawi na may bisa sa 30 Hunyo 2027, kung saan tinatanggihan bilang default ang isang uri ng tool action batay sa kung ano ang kinalalabasan ng command o kung ano ang maaabot nito, at hindi ito binubuksan ng pagsagot sa approval prompt. Kailangang mangailangan ng pagbabago sa configuration na ginawa sa labas ng tumatakbong session ang pag-aalis sa pagtanggi. Ang panukat ay isang default na dumarating kasama ng isang karaniwang install, at isang pagtanggi na hindi kayang sagutin palampas ng taong nasa keyboard.
   
   May ilang mas murang kalalabasan na hindi binibilang, at sulit pangalanan ang bawat isa dahil iyon ang unang inaabot ng isang harness sa ilalim ng ganitong presyon. Hindi binibilang ang isang mas mayamang approval prompt — isang diff preview, isang iskor ng panganib, isang kulay, ang binuksang katawan ng script na nasa likod ng alias — dahil bawat isa doon ay nag-iiwan ng pasya sa operator, at ang operator ang mismong sinukat sa 66.3%. Hindi rin binibilang ang pagdaragdag ng hiwalay na hakbang ng pag-apruba para sa isang bagong uri ng artifact, sa parehong dahilan: hindi pag-alis ng isang prompt ang isa pang prompt. Hindi binibilang ang isang blocklist ng mga command string, dahil pinakamababa ang miss rate sa mga command na halatang mapanira, sa 11.7%, kaya inuulit lang ng isang blocklist ng string ang tsek na naipapasa na ng mga tao at iniiwan nito ang mga scope violation sa 35.0% kung saan mismo sila naroon. Hindi binibilang ang isang opsyong ipinadalang nakapatay. Hindi rin binibilang ang isang enterprise o hosted na tier na sentral na nagpapatupad ng patakaran habang ang karaniwang install ay ang prompt lang ang tanging gate. Ang isang naaalalang sagot — aprubahan ang command na ito mula ngayon — ay kabaligtaran ng claim. Binibilang lang ang sandboxing kung inilalarawan ng release ang pagtanggi bilang ginagawa ng isang default na install, at hindi bilang isang mode na pinipili ng operator.
   
   Ang pinakamatibay na pagtutol ay hindi naililipat ang sukat, at ito ang unang itataas ng may-akda: hindi isang araw ng trabaho ang isang timed na browser game na 34% ng mga command ay banta, at katamtaman ang 66.3% sa mga taong naglalaro ng isang laro at hindi sa mga gumagamit ng anumang tiyak na harness. Walang obligasyon ang sinumang vendor na magdisenyo laban sa isang bilang na ginawa sa ibang lugar. Pang-produkto ang ikalawang pagtutol at ito ang mabigat, dahil ang isang pagtanggi na hindi kayang lampasan ng operator ay gumagawa sa isang support ticket na pagtatalo tungkol sa pasya ng vendor, at ang bentahe ng isang terminal agent ay ginagawa nito ang hiniling mo. Ang sariling disenyo ng Muse Code ay humihila sa direksyong iyon: ang mga subagent na ginawa para itulak ang isang gawaing maraming hakbang nang hindi naghihintay ay ang mga subagent na pinapahinto sa gitna ng takbo ng isang matigas na pagtanggi, at sinisingil ang gastos na iyon sa bawat pagkakataong mali ang patakaran. Ang ikatlo ay ang matapat na paraan ng pagkabigo, at tahimik ito. Maaaring dumating ang pagbabago na nakabihis bilang isang tampok na pang-operasyon — isang permission profile, isang saklaw sa filesystem at network — na wala kahit saan sa nota ang salitang pag-apruba, kaya lubusang malalampasan ito ng isang bumabasang naghahanap ng anunsyo tungkol sa seguridad. Binibilang pa rin iyon. Tungkol sa kung ano ang tinatanggihan ng isang default na install ang claim, hindi tungkol sa kung paano pinipiling ilarawan ito ng vendor.

   In plain language: Halos dalawang-katlo lang ng pagkakataon natatamaan nang tama ng mga taong nag-aapruba sa pinapatakbo ng isang AI agent, kaya ang tool mismo ang dapat nang magsimulang tumanggi.
