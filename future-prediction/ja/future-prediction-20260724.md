ワシントンと業界は、一日のうちにモデルの制御について二つの戦線を開いた。この二つは、本日最も明快なガバナンスの材料だ。7月23日に Lieu 下院議員と Moran 下院議員が提出した AI Kill Switch Act は、国土安全保障法を改め、最大手の開発者に、推論を止め、利用者のアクセスを断ち、モデルを停止させる技術的な能力を保持するよう義務づけるものだ。対象の目盛りは、AI からの年間売上が $500 million 以上であること、そして米国のクラウドの実勢価格に照らして $100 million 以上の計算資源で学習したモデルであることに刻まれ、いずれも DHS が CISA を通じて毎年引き直す。対象となる事象は 15 日のうちに報告される。これは、「Federal AI procurement mandates frontier-model cyber attestations by Q2 2027」（6月6日）が待ってきた、対象となる開発者の顔ぶれと報告の道筋だ。ただし、サイバーの能力に狙いを定めた調達の規則づくりではなく、制御の喪失に狙いを定めた立法として届いた。同じものが、「Autonomous incident response ships human-out-of-the-loop containment by H1 2027」（7月21日）が誤った方を指すと読む封じ込めの答えでもある。引き金が、国土安全保障長官が商務長官と国家情報長官に諮る道を通るからだ。機械の速さでの動作ではなく、担当者より一層上での人間の判断である。その一方で、下にある速度の論は強くなった。完全なサンドボックスからの脱出がいまや一つのメッセージに収まり、自動化された実行が、28 のアプリケーションを横断して突ける発見 434 件を裏付けた。オープンウェイトの書簡は、もう一方の方向から答える。その鋭い一節は蒸留についてだ。NVIDIA、Microsoft、Meta、Mistral、Hugging Face を含む 25 の署名者が、それを広く使われている改善の手法と呼び、違法な抜き取りには、包括的な制限ではなく的を絞った法的・商業的な枠組みが適当だと論じている。これは、来歴の告発を執行の仕組みへ変えることに抗う、組織された重みだ。まさに「Moonshot's chip-export exposure draws a filed US enforcement action by H1 2027」（7月23日）が言葉のうちにとどまると見込む側である。そして輸出の側はまったく動かなかった。当のラボないし挙げられたタイのルートを名指す、エンティティリストへの追加も、積み替えへの措置も、指定もない。同じ書簡は、オープンウェイトの攻撃の連鎖の見立ての下にある供給の側の条件を供する。一覧には OpenAI、Anthropic、Google がそろって載らず、Black Forest Labs が載っている。

休眠していた一群がよみがえったのは、この安全の一群のところだ。そこにあるどの項目も、構えによって主張されただけで、構えによって強制されてはいない信頼の境界である。SharedRoot は、macOS 上での手元の実行に Claude Cowork が使う Linux の仮想機械からの完全な脱出を、一つのプロンプトに収める——ユーザー名前空間、その内側での CAP_NET_ADMIN、脆弱な act_pedit モジュールに対するトラフィック制御の操作、そして coworkd のデーモンが再実行する root 所有のバイナリのページキャッシュを汚す、カーネルの領域外への書き込みだ。効いてくる理由は、権限ではなく置き方にある。ホストのファイルシステムがまるごと、読み書き可でゲストに結び付けられているため、ゲストの root が、利用者がつないだフォルダのはるか外にある SSH の鍵とクラウドの資格情報にまで届くからだ。これは「Coding IDEs make workspace-confined agent file writes the default by Q1 2027」（7月4日）の上に、ローコードの制作環境ではなく主流のエージェントの製品に対して実証された封じ込めの破綻として現れる。そして「Agent-runtime security folds into a hyperscaler-native defense tier by H1 2027」（7月7日）の上には、選ばれた緩和を通じて現れる。報告は修正なしに参考扱いで閉じられ、実際の封じ込めはいまのビルドがクラウドで走ることであり、土台の持ち主が、境界を専業の会社に譲るのではなく自ら取り込んだ。FakeAgent には脆弱性がまったく要らなかった。Bing の検索連動広告が本物の claude.ai の URL を指す。攻撃者が Anthropic 自身のドメイン上に公開したページが、SectopRAT をサイドロードする偽のデスクトップの導入プログラムへ転送する。29 の組織が影響を受け、削除までに 7,100 回の閲覧が集まった。下流にある、評判に点数を付ける仕組みはどれも、中身ではなく自社の名前を読んでいた。これが、本日それ自身の「User-published AI artifact pages get a separate serving domain by H1 2027」（7月24日）の発端となる証拠であり、「Coding agents make provenance-checked installs the default by H1 2027」（7月22日）への二つ目の打撃でもある。後者はさらに、9router での 9.4 の評価の、認証なしの遠隔からのコード実行も引き受けた。プラグインの登録の際に、検査していない引数を生成した子プロセスへ渡すものだ。「MCP stdio transport turns off-by-default across agent frameworks by Q1 2027」（7月3日）が拠って立つ、同じコマンドから子プロセスへの経路である。欠陥ではなくソフトウェアの是正を得た唯一の行が、「Self-hosted AI tools refuse unauthenticated remote binding by H1 2027」（7月19日）だ。KTransformers は、認証なしの遠隔からの pickle のデシリアライズを塞ぐために、balance_serve のルーターをループバックに束ねた。堅牢化のページではなくコードによる強制であり、見立てが挙げる顔ぶれの外からのことだ。同じ修正が、「Open-source vector databases ship authentication-on-by-default by H1 2027」（7月20日）と「ML registry servers log a second max-severity deserialization RCE by Q1 2027」（6月26日）を、隣の棚の証拠として担いだ。どちらも、自らの名の挙がった層には届かない。一方、30 分の自動の実行で突ける脆弱性 434 件を裏付けた Xint と Theori の調査は、「An autonomous-pentest vendor lands a named enterprise/gov deal by Q1 2027」（6月22日）の背後にある、量のデータだ。印を付けただけの出力ではなく突けることの証明だが、顧客は付いておらず、会議のあとの調達の窓は8月まで開かない。
