利用者の二つ目の継続する予測(高度な仕事には外部の API、日々には局所の LLM、そしてそれを押すのは SaaS の値上げ)は、局所の極では数週ぶりに良い日を得て、外部の極では土台の水準での読みを得た。そして値段の機関は三日続けて止まったままである。日々の局所の側は具体的な現物を得た。8月4日火曜に公表された Liquid AI の LFM2.5-2.6B は、26 億パラメータ、およそ 34 兆トークンでの事前学習、学習の途中で 128K まで広げた文脈窓を持ち、記憶 2.5 GB 未満に収まり、外部の API へ往復せず端末の側で完結する計画、ツールの呼び出し、多段の仕事に真っ直ぐ向けられている。公表当日から llama.cpp、MLX、vLLM、SGLang、そして transformers 5.0.0 以降の ONNX に対応する。測られた主張は同社自身のもので再現されていない。Apple M5 Max で毎秒 220 トークン、AMD Ryzen AI Max+ 395 で毎秒 113 トークン、NVIDIA H100 一枚を高い同時実行で使って出力毎秒 15,000 トークン近く、ToolSandbox で 77.83、これに対し Gemma 4 E4B-it が 65.00、Gemma 4 E2B-it が 52.40 である。持続する部分は、どの点数でもなく記憶の上限のほうだ。この公表がしていないのは、その上限を文脈の長さと結び付けることであり、それこそ日々の局所での配備が必要とする数字である。エージェントと呼ぶに値するほど長く走る反復は、ツールの出力と自らの記録を溜め込んでおり、手元の機械で足りなくなることは、規模の自動調整ではなく停止だからである。Unsloth は道具の側から同じ極を埋める。8月4日火曜の Studio リリース v0.1.524-beta で DSpark が既定で有効になり、推論の速さを二倍にすると述べられるが、比較の両側に毎秒のトークン数はない。XET から HTTP への自動の切り替えもあり、DeepSeek-V4 Flash 0731 の量子化は 83 GB から 162 GB まで、これに Moonshot の Kimi K3、2.8 兆パラメータのうち活性 1,040 億が並ぶ。いずれも民生の枠から遠く外れた成果物である。外部の極は、価格でも設備投資でもなく土台の水準で動いた。8月6日木曜に告知された AMD の Taalas を買収する確定契約は、価格も完了日もなく、通例の条件と規制当局の承認が残る。買うのはモデルごとの集積回路で、重みとデータの流れを回路の側へ埋め込む。およそ 100 層の部品のうちモデルごとに作り分けるのは金属の 2 層で、試作までおよそ二か月、TSMC の 6 ナノメートルの試作 HC1 は Llama 3.1 8B を毎秒およそ 17,000 トークンで提供した。これを Instinct、Helios、EPYC、ROCm へ取り込む、という。この筋が立てる償却の論が、買収として述べられたものである。モデルは固定され、残る変数はトークンあたりの費えだけで、その規模を担えるのは土台の持ち主だけだ。これに対し、今週のコーディングの実行環境は逆を向く。Muse Code が載っている Muse Spark 1.2 は、Meta Model API からも届く外部のモデルだからである。そして押し出す力はまったく働かなかった。トークン単位の料率も、モデルの購読料の変更も、API の表示価格も、今日の材料のどこにも現れない。この筋を押すはずの値上げは、否定されたのではなく観測されないままである。

利用者の三つ目の継続する予測(RL と LLM による予測性能の向上、そして土台、統治、実世界での配備の三つの脚が並行して固まること)は、掲げている学習の土台については何も得ず、統治の脚は人の関門についての計測として届き、配備の脚は今季の分が閉じている。混合エキスパートの学習の手順も、ルータだけの追加学習も、ルータを考慮した優位の分解も、超長文脈での安定性の結果も、今日は現れない。代わりに届いたのは学習の土台ではなく実行の土台であり、長い展開が生き延びるために必要なのはそちらである。Muse Code の下位エージェントは非同期に走り、仕事ごとに立ち上がるのではなく一つの対話の間ずっと残り、いつ報告するかを自分で決める。そしてモデルの呼び出し、ツールの実行、承認、編集のすべてが機械の内側の出来事の記録に書き足され、Meta はこれを、実行をそのまま再現でき再起動にも耐えるものにするしくみだと述べる。停止のあとは、作業木から状態を導き直すのではなく止まった地点からそのまま続く。留保は実在する。beta であり、記録は機械の内側にとどまって分散やホスト側での実行の保証はなく、Meta も Herdr も他社が採り入れられる共通の形式や接点を述べていない。二つの製品が中断をまたぐ生存を看板の性質として扱っていることは、標準化そのものではなく、その早い段階の姿である。この日が実際に着いた先は統治であり、着いたのは台帳ではなく関門のほうだった。企業の調達の境界の内側で動く自律の予測エージェントは、まさに人がその行為の承認を求められる相手である。時間に追われたおよそ 409,000 回の判断にわたる 66.3% の平均正答率、そのうち能力の境界が機械的に押さえる区分である権限の範囲を越える行為が 35.0% と最も多く見逃されたことは、統制は査読者ではなくテナントごとの能力の関門でなければならない、という現時点で最も強い論拠である。今日公表されたもののうち、署名された技能の登録所も、テナントごとの能力の関門も、人以外の識別子の統制の枠組みも、形式的検証の結果も一つもない。Muse Code の出来事の記録は、何が起きたかを記録するもので、何をしてよいかを縛るものではない。入力の質の側では、Cisco の水曜の一群が、この筋が追ってきた捏造された勧告の問題のちょうど反対の極にある。20.9.10、20.12.8.1、20.15.6、20.18.4、26.1.2 という実名の修正版、言明された悪用の状況、機器の設定にかかわらず及ぶと述べられた範囲、そして7月29日水曜に公表日を告げた事前通知があり、これは自動の修正の流れが仕事を作り出さずに扱える一件である。実世界での配備の脚はまた何も引かず、その暦は閉じたままだ。IEEE-RAS Humanoids 2026 はすべての応募の窓を閉じ、9月21日月曜の競技の通知から10月26日月曜の最終版の論文まで決定だけの暦として動き、その先に12月6日日曜から12月9日水曜まで Santa Clara Convention Center での会議が控える。生産ラインの記録も、人型のための方策の追加学習も、製造側での生産の輪の閉じも、今日の材料のどこにもない。
