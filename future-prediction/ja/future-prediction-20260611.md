オープンウェイトの筋は、6月10日の Google による DiffusionGemma の公開である。Apache 2.0 のもとで出荷された、Gemma 4 のバックボーン上の 26B の Mixture-of-Experts(アクティブ 3.8B)で、左から右への自己回帰デコードをやめ、256トークンのブロックを並列に精緻化して生成を最大4倍速める。H100 で 1,000 トークン/秒超、コンシューマ向け RTX 5090 で量子化時に約18GB VRAM で 700 トークン/秒超に達し、140以上の言語にわたる 256K のコンテキストを持つ。vLLM、Transformers、MLX、NeMo、Unsloth にネイティブで対応する一方、llama.cpp は「近日対応」とのみ記載されている。これは、米国オープンウェイトのフロンティアの予測(6月4日)に中程度の強さで効く。米国の各ラボが積極的にフロンティア規模のオープンウェイトを出荷し続けているという、その見立てが拠って立つ推進力の新たな裏付けだからである。ただし動かす軸は異なる。Artificial Analysis Index の数値は報告されておらず、Google は拡散版の品質が自己回帰型 Gemma 4 に及ばないと認め、本番運用を自己回帰モデルへ戻すよう案内しているため、指数スコアという読みには逆らう。同じ公開は、本日のより強い休眠復活も動かす。4月23日の企業向けローカル LLM 標準の行が、想定範囲への直撃で再点火した。すなわち、ローカル推論の標準として単一のハイエンドなコンシューマまたはワークステーション GPU で動くよう見積もられた、Gemma クラスで約27Bのオープンモデルである。相違は、DiffusionGemma が dense ではなく Mixture-of-Experts であること、1M ではなく 256K のコンテキストを出荷すること、そして GGUF/llama.cpp のエッジ経路を依然「近日対応」と記載していることだけである。

コーディングエージェントの筋は、Simon Willison の6月10日の datasette-agent 0.2a0 である。信頼の境界を基盤側へ押し込み、実行を中断して担当者にはい/いいえ・選択式・自由記述の回答を求める ToolContext.ask_user プリミティブと、明示的な人間の承認を得てからエージェントが書いた SQL を確定する save_query ツールを備える。中断された対話は永続化され、サーバの再起動を越えて残る。これは本日で最も整合性の高い裏付けを与え、目標に紐付いた完了検証の予測(6月7日)を中程度に前進させる。エージェントに自身の結果を自己認証させないという同じ拒否の姿勢だからである。ただしここでのゲートは人間が介在する承認であって、指標がいう自動で実物の対象を走らせるチェックではない。同じ公開を、Willison の6月9日の llm 0.32a3 アルファ版(ほぼすべてを Anthropic が公開したばかりの Claude Fable 5 が書いたと彼は言う)と合わせて読むと、エージェント連携標準の予測(6月9日)が生きるオープンな多ツールのエージェントスタックでの周辺的な勢いとなる。だがいずれの公開も、名のあるベンダー横断のプロトコルにも、IDE への採用にも、その指標が追うエージェント名簿にも触れないため、評価は低いままである。Fable 5 の作者性の言及も同様に、そのモデルを目に見える形にとどめるだけで、意図に応じた能力ゲートの予測(6月10日)には何も語らない。その対象 — Anthropic 以外のラボが自前の意図ゲートを公表すること — には動きがなかった。

半導体の筋は、予測群そのものの起点となった出来事の直接の続きであり反転である。6月8日(月)は反発し、Intel は約8.5%、Micron は約9%上昇して、前週金曜日の約1兆ドルの売り崩しから回復した。その金曜日には、Broadcom の慎重な AI チップガイダンスを受けて Nasdaq が4.2%下落しており、市場関係者はこの下落を見立ての変化ではなく流動性主導の売り崩しと呼んだ。アクセラレータ株の再評価の予測(6月7日)にとって、これは高く設定されたハードルという仕組みを裏付ける一方、将来の発火については決め手を欠く。市場予想どおりの新たな ASIC の約定が再びこの銘柄群を押し下げたのではなく反転であり、さらに主導役は、先の上昇を牽引したマーチャント GPU 銘柄ではなく国内ファウンドリの材料へと移ったからである。同じ変動の大きいタイミングは、計算資源の見立てに基づく IPO 混雑の予測(6月4日)が注視する SpaceX の価格決定のタイミングの内側に収まる。史上最大の発行と時を同じくした、AI 連動の心惹かれる下落である。だが月曜日の急反転と、発行そのものの価格決定に関する読みの不在により、混雑の兆候は観測ではなく示唆にとどまる。Nvidia の目標株価平均 300 ドルの予測(6月6日)は、ファウンドリ側の言及 — Nvidia が Intel の 18A プロセスを評価していること — のみで、アナリストの目標株価の動きもデータセンター売上の数字もなく、国内ファウンドリへの移行は、その見立てが必要とする GPU 需要の仕組みとは無関係に進む。同じ移行は、本日のもう一つの休眠復活でもある。4月22日のカスタム AI シリコンの行が再点火した。反発を牽引した2つの主役 — Alphabet が約300万個の自社チップの製造を Intel に委託したことと、Nvidia が将来の製品向けに Intel の 18A を評価していること — が、まさにカスタムでマーチャント外のシリコンの話題であり、それが指す二系統の力学を補強するからである。ただし、文字どおりの学習対推論の SKU 分割には一歩届かない。いつものとおり、名指された各発火 — 同じ週の反発を伴わずにこの銘柄群を押し下げる市場予想どおりの ASIC ガイダンス、レンジ下回りの IPO の約定や持続的な AI インフラの下落、54 近辺の実測オープンウェイト指数スコア、自動で機械検証する完了ゲート、競合ラボの文書化された意図ゲート — は、本日の証拠によって示されはしても、実現されてはいない。


## Relation to My Own Predictions

ユーザーの第1の継続予測(マルウェアとしての悪意あるローカル LLM + 基本的な安全策としてのゼロトラスト)は、本期間はおおむね静かである。本日のコーディングエージェントの公開のエージェント信頼の枠組みを通して間接的に触れられるのみで、いずれの側面についても、新たなエージェントスタックの CVE、MCP サーバの侵害、調達での強制の証拠はない。最も近いシグナルは Simon Willison の datasette-agent 0.2a0 である。その ToolContext.ask_user プリミティブは実行を中断して担当者にはい/いいえや自由記述の質問を投げ、save_query ツールは明示的な人間の承認を得てからエージェント生成の SQL を確定し、中断状態はサーバ再起動を越えて永続化される。これは、エージェントの自作の動作を無条件に信頼するのではなくゲートすべきものとして扱う制御面の発想であり、ゼロトラストの側面がいう「基盤を決して信頼しない」姿勢と同じである。とはいえ、これは武器化や認証の出来事ではなく、オープンソースの基盤設計の選択である。構造的防御の側では、唯一の動きは先を見たカレンダーのみである。Confidential Computing Summit(6月23-24日、サンフランシスコの Mint にて、認証付き推論とハードウェアで検証する認証)と、Zenity AI Agent Security Summit の確定したニューヨーク・ロンドン・アジア太平洋への拡大が、この見立ての場として背後に控える。ただし、出荷された制御ではなく予定された議題としてである。エージェント基盤の CVE の波も、MCP サーバ隔離の指標も、CISA の期限やベンダー適格性の仕組みも本日は出ておらず、武器化と連邦の強制の両側面は手つかずのままである。

ユーザーの第2の継続予測(高度な用途にはクラウド API、日常にはローカル LLM、SaaS の値上げが推進)は、ここ数日で最も濃いローカル側の裏付けを得る一方、クラウド側の側面は間接的にしか動かない。日常ローカルの側面は DiffusionGemma で強く実現する。Apache 2.0 のもとで量子化時に約18GB VRAM でローカルに動く 26B のオープンモデルで、コンシューマ向け RTX 5090 で 700 トークン/秒超、H100 で 1,000 トークン/秒超、140以上の言語にわたる 256K のコンテキストと、出荷初日からの vLLM、Transformers、MLX、NeMo、Unsloth 対応を持つ。これは、現行のフロンティア規模のオープンウェイトモデルを、出荷当日に単一のハイエンドなコンシューマまたはワークステーション GPU 上に、トークン単価ゼロで載せる。さらに、その双方向の注意機構を活かして出荷された Unsloth の数独ファインチューンは、まさにこの側面が追う Unsloth のレシピと、広がるコンシューマ GPU の対応範囲そのものである。Google が高 QPS のクラウド配信ではなく、速度が重視される低並列のローカル推論向けと明示的に位置づける、より速い並列デコードの特性は、日常ローカルへの移行が依存するオンデバイスの基盤を固める。高度なクラウドの側面はより軽く間接的である。Broadcom が引き金となった約1兆ドルの半導体売り崩しと月曜日の急反発は、クラウド側面が追うアクセラレータ各社の経済性とハイパースケーラ規模の基盤コストへの手掛かりである。ハイパースケーラ規模でしか元が取れない基盤が、実時間で値付けし直されている。ただし、本期間は不可避な圧力を明示的に駆動する新たな SaaS API のトークン単価の値上げは出ていない。よって本日は、日常ローカルの半分を堅いローカル推論のデータで補強する一方、クラウドの側面は含意にとどめる。

ユーザーの第3の継続予測(RL/LLM ベースの予測性能の向上)は、基盤の側面に一歩、ガバナンスに薄く一歩を得たが、現実世界への展開には何もない。基盤の側面では、DiffusionGemma が新たなオープンな Mixture-of-Experts のバックボーン(26B、アクティブ 3.8B、256K コンテキスト)であり、その拡散ヘッドは、小さなローカルモデルが得意とするタスクを変える。出荷初日の Unsloth の数独チューンが格子を並列の制約充足問題として捉え直したことは、非自己回帰・双方向デコードへの具体的な手掛かりであり、この側面が追う「コモディティハードウェア上の MoE」の対応範囲を広げる。さらに datasette-agent 0.2a0 と、Fable 5 が書いた llm 0.32a3 アルファ版は、この側面が同じく指すフロンティアラボの CLI でのサブエージェント分配の統合先を拡張する。ガバナンスでは、datasette-agent の中断-質問-再開のチェックポイントと人間承認の SQL ゲートが、自律的な予測エージェントが企業の調達ゲートで信頼される前に内部で動くべき、テナント単位の能力ゲートと監査・認証の境界への一歩である。ただし依然として、署名済みスキルレジストリの相互運用の結果も、NIST の非人間アイデンティティの制御プロファイルも、形式検証のプレプリントもない。現実世界への展開の側面は静かである。物理 AI の生産ラインの記録も、ヒューマノイドの方策の LoRA も、OEM の生産ループの完結も本日は出ていない。夏の AI チップのカレンダー — 7月22-23日の AMD の Advancing AI と、8月23-25日にスタンフォードで開かれる Hot Chips — が唯一の先を見た目印である。よって本日は基盤の側面を固め、ガバナンスに一歩を刻み、展開は手つかずのまま残す。
