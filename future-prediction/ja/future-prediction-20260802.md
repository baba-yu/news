8月2日日曜は、二つの立法府があらかじめ選んだ日付であり、しかも二つとも同じことのために選んでいる。EU AI Act の第50条が適用され始め、欧州委員会はこの朝に印を付けるように、自らの AI Office、各国の市場監視当局、European Data Protection Supervisor がそれを執行していることを認めた。覆われるのは四つの場面で、四つとも開示である。人と直に受け答えするシステムは自分が AI だと言わなければならない。作られた画像、音声、動画、文章には、見分けが付くよう機械が読み取れる印を付けなければならない。感情を読み取る仕組みや生体情報で人を分ける仕組みを導入する側は、それにさらされる人へ知らせなければならない。そして公共の関心に関わる事柄についてのディープフェイクと AI が書いた文章には、表示を付けなければならない。企業が負うのは最大で €15 million あるいは全世界の年間の売上高の 3%、EU 自身の機関・組織・部局は €750,000 までで、中小の企業への釣り合いの取り方も枠組みの中に書き込まれている。足場はどれも、その日付の当日に組まれたものではない。委員会は7月20日月曜に第50条の指針を採っており、AI が作った中身の透明性についての任意の Code of Practice——表示に使える EU の無料の図記号一式が付く、適合を示すための安い道筋——は署名者が 180 を超え、その最初の一覧も公表されている。AI Act そのものが効力を得たのは 2024年8月1日である。だから、法が存在してからこの条文が噛み付くまでのあいだには、二年と一日が横たわっている。

カリフォルニアの AI Transparency Act も同じ朝に効力を生じ、そこへ届いたのは狙ってのことである。可決された時点の SB 942 は効力を生じる日を 2026年1月1日と書いていた。AB 853 がその条項を書き換え、2026年8月2日にした。相手にする範囲は狭く、配管は重い。縛られるのは、月に百万を超える訪問者または利用者を持ち、州内で誰でも使える状態にある生成のシステムの提供者である。第50条のほうは、大きさの下限をまったく置いていない。そしてブリュッセルが機械の読める印を求めるところで、サクラメントは欄そのものを定めている。提供者の名前、システムの名前と版、中身が作られたか手を入れられた日時、そして一意の識別子。これらを画像、動画、音声の中に表に出ない形で埋め込ませ、あわせて利用者が自分で表に出せる表示と、費えのかからない検出の道具を求める。その道具は URL を受け取り、見つかった来歴をそのまま返し、提供者自身の web サイトを訪れずに呼び手が叩ける呼び出しの受け口を備え、渡されたものを必要以上に長く抱え込まない。自分のシステムを他社に貸し出す提供者は、同じ表に出ない開示の仕組みを契約で相手にも課さなければならず、借り手がそれを剥がしたと知ってから 96 時間のうちに、その許諾を取り消さなければならない。計器は一件あたり $5,000 で、守れていない日は一日ずつ別に数えられ、上限は書かれていない。それを回し始められるのは司法長官、市の法務官、郡の法律顧問のいずれもで、勝った原告には弁護士費用と諸費用が付く。だから負う額は、被告の大きさによってではなく、その不備がどれだけ長く続いたか、いくつの品に触れたかによって膨らむ。今日の分の後ろには、この先の二段がすでに日付を持って控えている。生成 AI をホストするプラットフォームと大規模なオンラインのプラットフォームが 2027年1月1日、撮影機器の製造者が 2028年1月1日である。二つのうち重いのはプラットフォームのほうだ。そこで求められているのが表示ではなく検出だからである。直前の十二か月にわたって月ごとの独立した利用者が二百万を超えていたプラットフォームは、利用者が上げてきた中身に、条件を満たす来歴のデータが付いているかどうかを判じなければならない。見つけたものを、そこで名の挙がっている生成のシステムか撮影機器と一緒に差し出し、利用者がそれを覗くか落とせるようにし、そうと知りながら剥がしてはならない。そしてプラットフォームは、取り込みの時点で、その中身をこれから見る人のうち誰がカリフォルニアの人かを知りようがない。

今日公にされたソフトウェアは手入れだけで、意外なのは、それが触れた先がどこだったかである。Unsloth は PyPI に 2026.8.1 を置いた。7月29日水曜の 2026.7.6 以来はじめての新しい版で、許諾は Apache-2.0 のまま、対応する Python も 3.9 以上 3.15 未満のままである。変更の記録は三行で、DeepSeek-V4 0731 への対応、Windows まわりの直しのひとまとめ、そしてモデルと仕組みの両方にまたがる一般の不具合の直しだ。同じ日の後の取り込みで、install.sh と install.ps1 の両方の指定が、その配布物についてもそれと並ぶ unsloth-zoo についても、五つある導入の経路すべてで 2026.8.1 以上へ上がった。だから新しく入れる人は、一巡遅れてではなく、その配布物が存在するその日に新しいほうへ行き着く。中身のある取り込み二件は、呼び手が渡した文字列がテンプレートの仕掛けに触れる経路の上にある。一件目は、Jinja の文字列リテラルの中へ差し込まれるテンプレートの文を逃がすものだ。「user's question」のようにアポストロフィが入るとリテラルがそこで閉じてしまい、構文の誤りが上がっていた。逃がしていないバックスラッシュが黙って解かれてもいて、LaTeX の命令は制御文字になって返り、Windows の経路はそのまま壊れた。二件目は、その助けをモジュールの高さへ引き上げ、二重引用符にも広げ、あらかじめ用意された会話のテンプレートへ差し込まれるシステムのメッセージにも当てるもので、あらかじめ用意された十五のテンプレートと十二の試験のメッセージにまたがって、うまく組み上がった数を 180 のうち 76 から 180 のうち 180 へ引き上げた。持っておく値打ちがあるのは、その数字である。180 のうち 104 の組み合わせが、呼び手が誰でも通る経路の上で失敗し続けていた。調整の道具立ての内側、しかも呼び出しのときにモデルが目にする指示文の組み立てのところで、である。

今日いちばん語られたのは、新しい版の公表ではなく一つの試しであり、そこには点数が一つも入っていない。Andrej Karpathy が Claude Opus 5 に、The Lord of the Rings の冒頭の段落と、およそ $10 にあたる百万トークンの持ち分と、three.js での描き出しの求めを渡した。モデルは人の手を離れておよそ二時間走り、多角形の部品を三次元の座標に手続きで置いて動かす、およそ 5,500 行のコードを返した。彼はそれを、粗いが面白い、と評し、自転車に乗ったペリカンの絵を求めてモデルを試す、あの土地からこの分野は離れはじめていると言った。この入れ替わりを数えておく値打ちを生むのは、その前後での一回の観測の費えである。ペリカンの指示文は Simon Willison のブログに自分の札を持ち、そこには 130 の記事が並んだ。そして 2026年7月には、そこへ統制された調べが加わった。Dylan Castillo のもので、八つの動物と六つの乗り物を掛け合わせて 48 の指示文を作り、七つの最前線のモデルにまたがって指示文ごとに温度 1.0 で三つずつ標本を取り、合わせて 1,008 枚の絵を引き、そのすべてについて動物、乗り物、そして動きの噛み合いを、人の手ではなくモデルによって一から五で採点した。各社が例の有名な指示文で学習していた証拠は見つからず、ペリカンは八つの動物のうち六位、ペリカンと自転車のます目は四十八のうち四十二位だった。一人で 1,008 回の観測を賄えたのである。後を継ぐものは、一回あたりおよそ $10 と、壁の時計で二時間かかる。その 1,008 回は、途切れず走らせて八十四日だ。だから今日そこに立っているのは、一つのモデルの上での一標本と、目で見ての判定であり、これを扱った記事もそう述べている。

この週末のハードウェアの結果は7月31日金曜に出て、今日拾われた。そして、書き手自身が述べている留保を抱えている。2.8 兆パラメータの Kimi K3 が、入力 1,024 トークン・出力 400 トークンで三つの構成に載せられた。NVIDIA B300 八枚がいちばん速く復号し、単一の流れで毎秒 172 トークン、まとめての山で 1,568、GPU 1基あたり 196。AMD MI355X 八枚は 118、952、119 を返した。二ノード・十六枚の B200 の構成は最下位で、90、498、GPU 1基あたり 31 である。加速器を倍積んで、一位の GPU 1基あたりの速さの六分の一に届かない。書き手はそれを計算力ではなく容量に帰している。この大きさのモデルは、HBM が足りている一つのノードならまたがずに載る。そして、またぐことがその費えになるからだ。時間に値が付くと、順序は裏返る。書き手が前提に置いた単価では、GPU 1枚1時間 $2.50 の MI355X の箱が 1ドル・1時間あたり毎秒およそ 48 トークンを返す。GPU 1枚1時間 $6.00 の B300 はおよそ 33、GPU 1枚1時間 $4.25 の二ノードの B200 はおよそ 7 である。そのすべての下に、一つの非対称が横たわっている。RadixArk の Kimi-K3-DSpark という下書きのモデルによる投機的復号——そこでは単一の流れの速さをおよそ 2.2 倍にするとされている——が述べられているのは MI355X の構成についてだけで、NVIDIA のどちらの構成についてでもない。その二つについては、この計測はどちらも CUDA で走らせていると記している。つまりこれは、走らせた中に無かったことが示されたのではなく、書き物の中に無いということである。そのまま受け取れば、費えの順序は、ある売り手の部品と別の売り手の部品の比べものではなく、述べられた一つの積み重ねと別の積み重ねの比べものになる。そしてそのすべてが、一人の書き手の仕掛けによる一つの仕事の形での計測であり、その書き手が前提に置いた GPU 1枚1時間の三つの単価に寄りかかっている。

この材料に照らして測られた、開いたままの主張は二十六件である。うち三件はこの朝に開かれ、二十三件が持ち越された。持ち越された二十三件のうち五件は、今日より前の七日のうちに開かれたものである。そして十二件が、この週末の公表によって眠りの溜まりから引き戻された。二つの目盛りは、きっかり一段だけ離れて座っている。しかも両端での振る舞いは、互いに同じではない。材料がその主張にどれだけ関わったかは、目盛りの真ん中あたりに付いた。範囲の頂上に届いたのは三度で、それはこの日自身の三つの主張についてであり、ほかにはない。そしていちばん下には一度も触れなかった。どれだけ決着させたかのほうは、そこからまる一点下に座り、三つ目の段より先へは一度も行かなかった。四つ目にも五つ目にも届いたものはなく、三つ目に届いたのが八件、いちばん下で終わったのが三件、そして残る十五件が、大きく引き離しての最大の一群として二つ目に座った。もっと鋭く読めるのは、証拠がどこに当たったかのほうである。二十六件のうち十七件は、主張の拠って立つ構造の力に当たった。五件はそれが予期する帰結に、三件はその下にある観察された前提に当たり、一件は空振りに終わった。時機と担い手の位置取りには、まったく当たっていない。前提に当たった三件は、まさにこの日が開いた三つの主張であり、持ち越された主張はそこに一件も当たっていない。新しい主張が、ほかのすべてを測るのに使われているのと同じ文書から切り出されているとき、見え方はこうなる。その文書とは、日付に届いた二つの透明性の決まり、手入れの版、研究者の書き物、そして第三者の計測である。この類の道具は、力は動かすが、決着はほとんど付けない。

三つ目の段に届いた八件は、持ち越された組と引き戻された組のあいだで、偏った分かれ方をしている。この日自身の三件がそこにいるのは、前提が記録に載っているからであって、それ以上ではない。1ドル・1時間あたりでいちばん安い構成だけが下書きを走らせていると、それ自身が述べている計測。しかもその下書きは、公表者が一度も出荷しなかったものである。プラットフォームの段を 2027年1月1日に日付づけた条文。そして、人の手を離れた一回の長い走りを、人の手を離れた一回の長い走りとして正直に報せたもの。そこまで届いた持ち越しの五件のうち、四件は眠りから戻ってきたものである。「Local-LLM runtimes ship in-model speculative decoding on by default by Q2 2027」（7月5日）が得たのは、その技法が見出しになった費えの結果を決めたとされ、この書き物がそれを述べているのは三つの構成のうち一つだけで、それでいていまなお第三者のチェックポイントから手で組み上げられている、という場面だった。「Unsloth ships day-of fine-tuning for the next 1T+ open-weight release by Q1 2027」（7月7日）は、同じ週のうちの対応を得た。そして今回は、導入器の指定が一巡あとではなく公表の当日に動いている。ただし、この主張が要とする規模をだいぶ下回るチェックポイントに対してである。「Local fine-tuning toolkits absorb the model-serving layer by default by H1 2027」（7月8日）は、学習の企てが公表の当日を、呼び出しのときに指示文がどう組み上げられるかに費やす場面を得た。「Orchestration benchmarks add a latency-disclosure column by Q1 2027」（6月24日）は、二時間とおよそ十ドルが、その下に埋めてしまえる正しさの数字を一つも持たないまま、能力の主張の見出しとして引かれるのを得た。五件目の「Kimi K3's full weights run on one 640GB node via expert offload by Q4 2026」（7月25日）は、常駐が計測の全体を決め、そして退避の道そのものは試されないまま残るのを得た。この比べもののなかで、専門家を一つでもホストのメモリから流し込んだものはなかったからである。

いちばん下で終わった主張は三件あり、そこで終わった理由は二通りである。二件は逆に切られた。「Disaggregated expert-parallel serving becomes the default for 2T MoE by H1 2027」（7月20日）は、この日の唯一の計測が逆を指すのを見た。2.8 兆パラメータのモデルを二つのノードに広げた構成が GPU 1基あたり毎秒 31 トークンを返し、一つの箱に加速器を八枚収めた構成の 196 に対してだったからである。どちらも CUDA の構成で、この書き物はそのどちらについても下書きを挙げていない。そして 1ドル・1時間あたりではおよそ 7 で、この比べもののなかで最も低い費えの数字だった。「Closed-weight frontier crystallizes as open weights cap at 35B-A3B by Q3 2026」（4月21日）は、開かれた側の半分でまた壊れた。週末じゅう GPU 1時間いくらで値を付けられていたモデルが、それが挙げる上限より何桁も上に座り、しかもありふれた基盤として提供され調整されているからである。いっぽうで閉じた側の半分は、この日の見出しになった能力の主張が、役務としてしか届かないモデルから出てきたという見立ての上で生き延びた。三件目は、そもそも反証ですらない。「Oracle swaps a named Gemini tier out of its Fusion model list by H2 2027」（7月31日）が、この日の唯一の空振りである。その主題は何も公にせず、モデルの一覧も動かず、掲げられた二つの段はどちらも、どこにも口に上らなかった。さらに二件が一段上で切られていて、そのどちらも役に立つほうの切られ方だ。縛る文をもつ場は、能力で関門を作るほうへではなく、そこから離れるほうへ動いた。降りた二つの成果物のどちらも、サイバー、生物、整合性のいずれの試験も挙げておらず、カリフォルニアの敷居は月ごとの利用者の数だからである。そしてシリコンを選ばない提供は、無料で手に入るものだと分かった。開かれた枠組みに駆動ソフトの直しを足したものが、先端の規模のモデルを CUDA の外へ運び、この表で最良の費えの数字まで届いたのである。しかもそれは、この書き物が下書きを走らせているとも述べている、ただ一つの構成の上でのことだ。それはこの能力を欠かせないものにすると同時に、加速器の売り手がコンパイラを手にするために払う理由を弱める。
