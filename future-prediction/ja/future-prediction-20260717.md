ユーザーの 1 つ目の常設予測（悪意あるローカル LLM のマルウェア化と、根本的な防御策としてのゼロトラスト）は、ここ数週間で最も直接的な一日を迎え、両極がともに強く現れた。悪用の極は Check Point の AI Security Report 2026 だ。同報告書は、AI が開発補助から実戦の攻撃実行者へと踏み越える様子を記録している。侵入は、人間の指示を最小限に、数千のコマンドと数十のセッションにわたって自律的に実行され、ある攻撃者は VoidLink——88,000 行のコマンド&コントロールフレームワーク——を 1 週間足らずで構築し、長い悪性ペイロードは 3 月から 5 月にかけて約 5 倍に増え、高リスクの AI とのやり取りは前年比で倍増してプロンプトの約 4% に達した。その最も鋭い発見は、この仮説がいう汚染されたアーティファクトの形にまさに合致する。攻撃者は、エージェントがセッションをまたいで自動読み込みする設定ファイル——エージェントがユーザーに代わって読み込むリポジトリやコンテキストファイル——に永続的なバイパスを仕込む。これは、この仮説が指す、武器化されたローカルツールという経路が、モデルレジストリではなく設定ファイルを通じて到来したものだ。ゼロトラストの極は同じ日に出荷された。Claude Code v2.1.212 は、アナライザーが bash とは異なる解釈をするファイルディスクリプタのリダイレクト形式に対して、失敗時に遮断する Bash 権限チェックを有効化し、Windows PowerShell 5.1 の権限バイパスを塞ぎ、10,000 文字を超えるコマンドに確認を強制し、暴走する検索やサブエージェント生成のループを既定で抑える。失敗時に遮断され、能力でゲートされた実行が、主流のエージェントの既定となった——これは、この仮説が見込む構造的な防御の姿勢だ。この一日は、攻撃とその答えがともに現れた、防御側の裏づけとして読める。大規模に計測された設定ファイルポイズニングが脅威であり、既定で有効な失敗時遮断の権限ゲーティングが、まさにその対応である。
