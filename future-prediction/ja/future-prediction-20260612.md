## Summary of Findings

本日の動きは、同じ AI 構築の、緩く結びついた3つの筋を織り合わせている。そして主役は、エージェントの展開思想における明快な分岐であり、対極にある2つの同日公開として現れる。クラウド側では、OpenAI の6月11日の Ona(名称変更後の Gitpod、Codex グループに統合)の買収が、コーディングエージェントを永続的なクラウドサンドボックス内で走らせる製品を手に入れる。これにより、数時間や数日のタスクは開発者のワークステーションの電源を切った後も実行され続け、戻ったときに確認される。欧州の業界報道は、これを Anthropic が企業内で支配する、再起動を越えて生き残る永続的な実行基盤を OpenAI が買うものと明示的に位置づけ、コーディングエージェントの争いを、素のモデル能力からランタイムを誰が握るかへと一段下げると描く。ローカル側では、Moonshot の6月12日の Kimi Work が、Apple シリコンと Windows 向けのダウンロード可能なデスクトップエージェントを出荷する。これはユーザーのマシン上で直接、約300個のサブエージェントから成る Agent Swarm を束ね、WebBridge 拡張を通じてログイン中のブラウザを操作し、組み込みの cron エンジンと keep-awake トグルで夜間ジョブを実行し、変更が承認されない限り元のファイルには手を付けない。すべては、オープンウェイトの Kimi K2.6(Mixture-of-Experts、トークンあたりアクティブ約32B、256K コンテキスト)上で動き、同じ重みは Unsloth の2ビット(UD-Q2_K_XL)動的量子化でオンデバイスでもすでに実行できる。この分岐が本日で最も整合性の高い裏付けである。これは、持続的な ask-user チェックポイントの予測(6月11日)に、両極でセッションを越えて生き残る実行とオペレータのチェックポイントとして関連性4で効き、コンシューマ GPU のコーディングエージェントがクラウド専用 API を置き換えるという休眠行(4月26日)を、クラウド専用 API に対する具体的なローカル優先の代替として復活させる。ただしハーネスの名のある再開可能な中断プリミティブには届かず、開発者シェアの数値もない。

オープンウェイトの筋は、Zyphra の6月12日の Zamba2-VL の公開である。Apache 2.0 のもとで Hugging Face にチェックポイントを置く、1.2B/2.7B/7B の Mamba2-Transformer ハイブリッドの視覚言語ファミリーで、言語のバックボーンは Mamba2 の状態空間層といくつかの共有トランスフォーマーブロックを組み合わせ、Qwen2.5-VL の Vision Transformer を2層の MLP アダプタで再利用する。32Kトークンのプリフィルで最初のトークンまでの時間を約1桁短縮し、小さなモデルが認識で実力以上の成績を出す(2.7B は PixMoCount 82.5、CountBenchQA 87.5、DocVQA 90.9、1.2B は PixMoCount 62.5 で InternVL3.5-1B の 32.8 のほぼ倍)。これは、米国オープンウェイトのフロンティアの予測(6月4日)には、Artificial Analysis Index の数値を欠く公開頻度の証拠として弱く効くにとどまり、オープンウェイトのテキスト拡散の予測(6月11日)にはアーキテクチャの系統が誤って触れ(拡散ではなく状態空間ハイブリッドで、GGUF 経路もまだない)、27B dense / 1M コンテキストのローカル LLM 標準の休眠行(4月23日)を、ローカル展開という方向性で緩く復活させつつ、具体的な軸のすべてで食い違う。第3の筋は企業活動である。Anthropic の6月1日の非公開 Form S-1 の草案(650億ドルのラウンド、ポストマネー9,650億ドル、2月から3倍超に伸びた年率換算収益470億ドル超)が、OpenAI の最大1兆ドルの評価額で600億ドル超と報じられる調達に対抗する IPO シーズンを準備し、その背景は6月11日に具体化した。SpaceX が5億5,560万株を135ドルで価格決定して約750億ドルを調達したのである。これは Saudi Aramco を上回る史上最大の IPO で、Nasdaq に SPCX として上場する。一方で OpenAI と Oracle は、Oracle Cloud の顧客が新たな調達経路なしに対象の Universal Credits を OpenAI のフロンティアモデルと Codex へ振り向けられるようにした。これは、計算資源の見立てに基づく IPO 混雑の予測(6月4日)の供給側を関連性3で濃くし、SEC の計算事前購入開示の休眠行(5月30日)を復活させる。だが混雑の読みそのものは欠けている。レンジ下回りの約定も、既上場の AI インフラ銘柄全体の実測の下落も、SEC の動きもない。夏の AI イベントのカレンダーは、あくまで先を見た背景として下を走る。本日閉幕する WWDC26、6月15-18日に Moscone で開幕する3万人規模の Databricks Data + AI Summit、そしてセキュリティ(6月23-24日の Confidential Computing Summit、8月4日の Black Hat USA の AI Summit)とチップ(7月22-23日の AMD Advancing AI、8月23-25日の Hot Chips)の各トラックである。よっていつものとおり、名指された各着地は、本日の証拠によって示されはしても、実現されてはいない。


## Relation to My Own Predictions

ユーザーの第1の継続予測(マルウェアとしての悪意あるローカル LLM + 基本的な安全策としてのゼロトラスト)は、本期間はその武器化と連邦の強制の側面についておおむね静かである。本日の2つのエージェント公開の信頼境界の枠組みを通して間接的に触れられるのみで、新たなエージェントスタックの CVE も、モデルレジストリの侵害も、MCP サーバ隔離の指標も、CISA の期限の仕組みも出ていない。最も近いシグナルは、攻撃ではなく制御面の発想である。Moonshot の Kimi Work は、ユーザー自身のマシン・ファイル・ログイン中のブラウザセッション上で直接、約300個のサブエージェントの swarm を走らせるが、変更が承認されない限り元のファイルには手を付けない — エージェントが書いた動作に対する明示的な人間の承認ゲートである。一方 OpenAI の Ona は、コーディングエージェントの実行をラップトップから永続的なクラウドサンドボックスへと移し、隔離されたコンテナをエージェントが動く基盤とする。両者はエージェント実行を、既定で封じ込めゲートすべきものとして扱い、ゼロトラストの側面がいう「基盤を決して信頼しない」姿勢と同じであるが、これらは汚染されたチェックポイントや認証の出来事ではなく、製品設計の選択である。構造的防御の側では、唯一の動きは先を見たカレンダーのみである。Confidential Computing Summit(6月23-24日、サンフランシスコの Mint にて、認証付きエージェントと安全な AI ワークフローを扱い、AMD・Google・Microsoft・NVIDIA・Samsung・UC Berkeley が登壇)と、Zenity AI Agent Security Summit の確定したニューヨーク・ロンドン・アジア太平洋への拡大が、出荷された認証の制御ではなく場として、この見立ての背後に控える。よって武器化と調達ゲートの両側面は手つかずのまま残り、構造的な答えは議題としてのみ用意されている。

ユーザーの第2の継続予測(高度な用途にはクラウド API、日常にはローカル LLM、SaaS の値上げが推進)は、ここ数日で最も濃い裏付けを得る。本日のエージェント層の分岐が、この見立てが引く「高度はクラウド対日常はローカル」の継ぎ目のほぼ真上に着地するからである。高度なクラウドの側面は OpenAI の Ona 買収で実現する。Codex(週500万ユーザー超)が長期にわたる数日がかりの作業を完遂できるよう永続的なクラウドサンドボックスの基盤を買うことは、この側面が指す「フロンティアのワークロードはハイパースケーラのクラウドにとどまる」力学そのものであり、Universal Credits を既存クラウドの経路で OpenAI のフロンティアモデルへ振り向ける OpenAI-Oracle の取り決めと、IPO の積み上がり(Anthropic のポストマネー9,650億ドル、OpenAI の最大1兆ドルの目標、SpaceX の記録的な750億ドル調達)によって補強される。これらは、フロンティアの基盤がハイパースケーラと公開市場の規模でしか元が取れないことを際立たせる。日常ローカルの側面も同じくらい強く具体的に実現する。Moonshot の Kimi Work はオープンウェイトの Kimi K2.6 上で常駐のローカル swarm を走らせ、公開報道は同じ重みが Unsloth の2ビット動的量子化を通じてすでにオンデバイスで動くことを強調する — まさにこのローカル側面が追う Unsloth のレシピと、広がるコンシューマおよびワークステーションの対応範囲である。さらに Zyphra の Apache 2.0 の Zamba2-VL は、速く完全にライセンスされた 1〜7B の視覚言語モデル(最初のトークンまでの時間が約1桁速い)を、API エンドポイントではなくエッジハードウェアの手の届く範囲に置く。不可避な圧力を明示的に駆動する新たな SaaS API のトークン単価の値上げは出ていないが、本日は両極のハードなデータとともに、ここ数週で最も明快な「高度はクラウド・日常はローカル」の対比を供給する。

ユーザーの第3の継続予測(RL/LLM ベースの予測性能の向上)は、基盤の側面に確かな一歩、ガバナンスに薄く一歩を得て、現実世界への展開には何もない。基盤の側面では、Kimi K2.6 が新たなオープンな Mixture-of-Experts のバックボーン(トークンあたりアクティブ約32B、256K コンテキスト)であり、その Kimi Work ハーネスは約300個の並列サブエージェントを束ねる — この側面が指す、長期にわたる多数ロールアウトのサブエージェント分配についての具体的な手掛かりである。一方 Ona の永続的なクラウドサンドボックスは、自律的な予測エージェントの数日がかりのロールアウトが依存する永続実行を広げ、Zyphra の Mamba2 の状態空間ハイブリッドは、この側面も追う「コモディティハードウェア上の非トランスフォーマー」の対応範囲を広げる。ガバナンスでは、Kimi Work のファイル承認ゲートと Ona の戻ったときの確認チェックポイントが、こうしたエージェントが企業の調達ゲートで信頼される前に内部で動くべき、テナント単位の能力ゲートと監査・承認の境界への一歩である。ただし依然として、署名済みスキルレジストリの相互運用の結果も、NIST の非人間アイデンティティの制御プロファイルも、形式検証のプレプリントもない。現実世界への展開の側面は静かである。物理 AI の生産ラインの記録も、ヒューマノイドの方策の LoRA も、OEM の生産ループの完結も本日は出ていない。夏の AI チップのカレンダー — 7月22-23日の AMD の Advancing AI と、8月23-25日にスタンフォードで開かれる Hot Chips、そして9月15-17日の AI Infra Summit の物理 AI トラック — が唯一の先を見た目印である。よって本日は基盤の側面を固め、ガバナンスに一歩を刻み、展開は手つかずのまま残す。
