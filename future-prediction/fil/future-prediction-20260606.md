Ang pinakamatalas na suporta ng araw ay ang Flowise CVE-2026-40933 disclosure: isang CVSS 9.9 OS command injection sa Model Context Protocol stdio adapter ng framework. Doon, ang isang one-click chatflow import ay nag-e-execute gamit ang sariling privileges ng host process at walang confinement.
