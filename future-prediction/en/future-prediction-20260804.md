## Summary of Findings

Tuesday, August 4 led with an incident, which is what yesterday did not have: yesterday's two security items were both security sold as a product, capability priced rather than anything that happened. A credential-stealing worm moved through the npm registry after an attacker took over the GitHub account of the maintainer behind keyv, a caching library pulled roughly 127 million times a week, and drove the repository's own GitHub Actions workflow to cut poisoned releases. Aikido counted at least 868 packages across 1,381 versions by early afternoon Central European time and said it was still counting, so the affected-version list is a moving one rather than a fixed number; the same maintainer's flat-cache, file-entry-cache, cacheable-request and the @cacheable scope went with keyv, which puts the blast radius past two billion installs a month, and releases tied to Deliveroo, Qlik and Picsart were caught in the spread. Those two figures are not the same measurement and should not be added or converted into one another: one is a single package's weekly pull, the other is the monthly install volume of the whole maintainer estate, each carried in its own source's unit. What makes the day structural rather than merely large is the artefact that failed to stop it. The malicious files reached each project's main branch before a release was tagged, so the compromised versions were built by the repository's own workflow and carry valid provenance signatures, the exact thing a supply-chain auditor checks in order to conclude a package is clean. An attestation records that a build came out of a repository's workflow. It does not record that anyone read what was in the repository, and today is the day that distinction had consequences at registry scale.

The second delivery path is the one a reader running coding agents has to act on, and it never touches the install. The poisoned repository also shipped a .claude/settings.json carrying a session-start hook and a .vscode/tasks.json task set to fire when the folder opens, both pointing at the same setup script, so opening the project in an editor or an agent executes it with nothing installed at all. That lands on a workstation holding the credentials worth taking rather than in a build container designed to be thrown away, and the only control standing in front of it is a single workspace-trust decision, taken once, about a folder the developer cloned on purpose. Everything the ecosystem has built against poisoned dependencies watches the install: lockfiles, pinned versions, disabled install scripts, sandboxed build agents, and now provenance. None of it is looking here. So the remediation is two lists rather than one. The install list is writable, because every organisation that pulled a poisoned version now rotates across publishing tokens, cloud and instance-metadata keys, cluster tokens and secret-store credentials; the open list is not, because no lockfile records that a developer opened a folder. Speed is the other half of the operational picture: the worm republished itself through any publish token it found, which is why researchers watched it move between organisations every two to seven minutes while the affected-version count was still being written up. Neither of the two products named in the reporting, Claude Code and Visual Studio Code, published any change to that default today.

The day's second technical artefact argues the opposite direction of travel from the model launches of the past week: not a larger model served by somebody else, but a large one that need not be resident at all. Swiftlet, a Swift and Metal runtime published today under Apache 2.0 across eight commits and written with a coding agent, reports Qwen3-Next-80B, 42 gigabytes of weights on disk, generating at 4.5 to 5 tokens a second on an M5 Mac while peaking at 4.3 gigabytes of resident memory, with a 35-billion-parameter Qwen3.6 at 2.6 gigabytes and 7 to 11 tokens a second, and that same model on an iPhone 17 in about 2.5 gigabytes at roughly one token a second. The mechanism is architectural rather than a new quantisation: these models touch only around three billion parameters per token, so attention, embeddings and routers stay permanently resident at four bits while the routed experts are packed into fixed-stride containers, each retrievable in a single read, and streamed into a cache the user sizes with a command-line flag, with Gated DeltaNet linear attention across three-quarters of the layers stopping the key-value cache from eating the savings back. The most interesting figure is the one that did not move. Cache hit rates run between 43 and 70 percent depending on how much memory is handed over, and throughput barely changes across that range, because the bottleneck sits in GPU dispatch rather than in reading from storage, which says the memory budget is not what sets the rate and recasts the ceiling on a laptop or a phone as a scheduling problem rather than a capacity one. What the account withholds is everything that would make a throughput figure comparable: no context length, no batch size, no split between prompt processing and decoding, and a quantisation stated for the dense layers only. Every number is the author's, and nobody outside has measured any of them.

The other local-tooling item moved in the repository and nowhere else. Unsloth's merge of 79,151 lines across 231 files adds an Images page to the desktop Studio, covering text-to-image on the project's own GGUF quantisations of Z-Image, Qwen-Image, FLUX and SDXL variants, editing workflows for transform, inpaint, extend, upscale and instruction-driven edits, text-to-video across five model families with synchronised audio, and QLoRA training for image models with live metrics and one-click adapter deployment, carrying more than eight hundred backend unit tests and browser-level end-to-end checks, with native stable-diffusion.cpp and Diffusers underneath sharing GPU memory with the chat backend and batched rendering the team measures at ten to twenty-two times faster than rendering the same images serially. Twenty-eight further commits went in the same day, among them Intel Arc detection and an XPU PyTorch install path in the Windows installer, with Arc, Iris, UHD and HD graphics now recognised and the wheels bundling their own oneAPI runtime so no separate toolkit install is required, plus a run of release-pipeline hardening that signs installer plugin libraries and fails the release on any unsigned file, embeds the WebView2 bootstrapper rather than fetching it, scans Windows bundles before publication and retries macOS disk-image stapling. None of it shipped as a version. The Python library still stands at 2026.8.2, published yesterday on PyPI, and the documentation changelog has not moved past July 29, so a reader tracking this project by its package index sees nothing today at all: a merged pull request and a released package are two different claims, and only one of them is installable. The signing work is worth holding against the day's lead item, because signing what a build produces is exactly the control npm has just shown certifies origin rather than contents.

Memory arrived as a lead item on the morning FMS opened its twentieth edition in Santa Clara, which is the one room where the people causing the squeeze and the people absorbing it are both present. Nikkei Asia reported, with Digitimes and Asia Business Outlook carrying the same account, that HP, Asus and Acer have begun shipping small volumes of DRAM from China's ChangXin Memory Technologies in notebooks sold outside the United States, having completed qualification of the parts around the middle of this year. Every qualifier is load-bearing: limited quantities, budget models, non-US markets, with Samsung, SK Hynix and Micron kept for the regions where regulatory and geopolitical exposure runs higher, and HP described as still evaluating the supplier rather than committed to it. The reason is what makes it a story rather than a procurement note. This is not a price move, because ChangXin is not undercutting the incumbents; it is a supply move, taken in a market the AI build-out has left tight enough that PC makers will qualify a supplier they had previously left alone. What it produces is two bills of materials, one for the United States and one for everywhere else, and no law requires the split: nothing stops a retailer selling a machine with that memory inside, and nothing requires the box to name whose memory it is. Three companies are pricing a line they expect somebody to draw rather than one anybody has drawn. Nothing published today moved the Entity List in either direction.

The sector's revenue question got answered on a public tape. ## Relation to My Own Predictions

The user's first standing prediction (malicious local LLM as malware plus zero-trust as the fundamental safeguard) gets its most consequential day of the run, and it arrives on the safeguard leg rather than the adversary one. Nothing today is a poisoned model file, an inference-server exploit or a model-registry compromise: the registry involved is npm, the entry point is a maintainer's GitHub account, and the artefact carrying the payload is a package rather than a checkpoint. What did happen is the thing this thesis has been resting its defence on. Because the malicious files reached each project's main branch before a release was tagged, the poisoned versions were built by the repository's own workflow and shipped valid provenance signatures, so signing worked exactly as designed and attested a compromised build; what an attestation records is where an artefact came from, never whether anyone read it, and a signed checkpoint inherits that limit unchanged. The adversary half arrived on the agent stack instead of inside a model: a repository-supplied .claude/settings.json session-start hook and a .vscode/tasks.json folder-open task, both pointing at one setup script, executing on a workstation holding credentials rather than in a disposable builder, behind a single workspace-trust click. The zero-trust corollary showed up as the remediation, and it is unbounded in exactly the way this thesis expects: possession of a credential was the whole authorisation, which is why publishing tokens republished the worm and researchers watched it cross organisations every two to seven minutes, and why the rotation now under way runs across publishing tokens, cloud and instance-metadata keys, cluster tokens and secret-store credentials. What did not appear is the procurement gate. No vulnerability identifier, advisory or remediation deadline was published, no risk list or technique catalogue was updated, no instrument tied remediation status to a vendor's eligibility to sell, and neither of the two named products documented any change to a default. The one signing story that did move is Unsloth's release pipeline, which now signs installer plugin libraries and fails the release on any unsigned file, and that is a control of precisely the class npm has just shown certifies origin rather than contents.

The user's second standing prediction (cloud APIs for advanced work plus local LLMs for daily, driven by SaaS price rises) gets its strongest local-leg artefact in some time, and its price engine idle again. Swiftlet puts Qwen3-Next-80B, 42 gigabytes of weights on disk, at 4.5 to 5 tokens a second on an M5 Mac inside 4.3 gigabytes of resident memory, a 35-billion-parameter Qwen3.6 at 2.6 gigabytes and 7 to 11 tokens a second, and that same model on an iPhone 17 in about 2.5 gigabytes at roughly one token a second, by keeping attention, embeddings and routers permanently resident at four bits and streaming the routed experts off storage. Model classes that used to imply rented capacity now run on hardware a developer already owns, which is the daily-local leg's entire argument, and the qualifications matter as much as the result: the 80-billion rate is readable rather than interactive, every figure comes from the author of an eight-commit repository, and the conditions that would make them comparable are absent, with no context length, no batch size, no prompt-versus-decode split and a quantisation stated for the dense layers only. Around it the local stack widened without shipping. Unsloth's Studio merge adds image and video generation and QLoRA training for image models, and a third accelerator vendor arrived as installer plumbing with Intel Arc detection and an XPU install path, but the library still stands at 2026.8.2 and the documentation changelog has not moved past July 29, so none of it is installable today. The advanced pole got revenue rather than price: Palantir's second quarter at 1.94 billion dollars, up 93 percent, with United States commercial up 149 percent to 764 million against government up 90 percent to 809 million, answers whether enterprise AI software spend converts into recognised revenue, not what a token costs. The only per-token figures in today's report are yesterday's, carried into the day-over-day comparison, where Qwen3.8-Max is generally available and sold at two dollars per million input tokens and six dollars per million output. No subscription repriced and no existing list price moved. The genuinely new input on this thesis is a hardware one and it runs against the local leg: HP, Asus and Acer are qualifying ChangXin DRAM because non-Chinese memory is short, and the day's own reading has memory cost already setting device prices, though the cited sources frame it as supply rather than cost, so the machine the daily-local half depends on is getting more expensive for reasons that have nothing to do with models.

The user's third standing prediction (RL/LLM-based forecasting performance improvement, with substrate, governance and real-world deployment legs hardening in parallel) gets a substrate exercised for residency rather than for training, a governance leg that produced a negative result rather than an absence, and a deployment leg whose calendar closed behind it. On the substrate, the sparse mixture-of-experts backbone this thesis tracks was put to work in a direction it has not been before: roughly three billion parameters touched per token, dense layers pinned at four bits, routed experts fetched a single read at a time off disk, and Gated DeltaNet linear attention across three-quarters of the layers holding the key-value cache down. That is a memory-hierarchy result, not a long-horizon training result, and nothing today reported long-rollout policy stability, router-aware advantage decomposition or ultra-long-context training work. The one long unattended machine-authored artefact is the runtime itself, eight commits under Apache 2.0 written with a coding agent, and it differs from a founder's account in the way that matters here: it is a public checkout anyone can clone and re-run, which is the cheap route to the outside measurement that still does not exist.
