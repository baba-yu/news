The security half of the day arrived as a shipped default rather than an escape. Noma Labs disclosed CVE-2026-59726, which it named RufRoot, on Wednesday, July 29, with the trade write-ups following on Thursday, July 30, at the maximum CVSS score of 10.0. The affected project is Ruflo, an open-source multi-agent orchestration platform serving as a harness for Anthropic's Claude and OpenAI's Codex, with more than 66,500 GitHub stars. Its Model Context Protocol bridge is an Express.js server brokering every tool invocation across agent workflows; that bridge's POST /mcp endpoint carried no authentication and the shipped docker-compose bound port 3001 to 0.0.0.0, so a default self-hosted deployment published 233 high-privilege tools, shell command execution among them, to anyone who could reach the port. One unauthenticated request invoking the terminal-execution tool runs commands inside the container; from there an attacker reads stored user conversations, lifts the environment variables holding model API keys, reaches a MongoDB instance running without authentication, spawns agent swarms billed to the victim's own keys, and poisons the AgentDB learning store so that the outputs served to every other user of that deployment are tainted. Maintainer Reuven Cohen shipped version 3.16.3 within 24 hours of the June 30 responsible disclosure, binding the bridge to loopback, requiring a bearer token, gating terminal execution behind explicit opt-in and enabling MongoDB authentication. The half that does not patch away is the memory.

The other security document is the control case for a story this book has carried since early July. Unit 42 published on Thursday, July 30 a reconstruction of a campaign in which an operator tracked as knaithe, based in Zhuhai, wired DeepSeek into the Hermes Agent framework and drove it from Telegram as an autonomous offensive operator, with the observed autonomous phase running in early May 2026. The agent enumerated vulnerabilities across ten product families, pulled proof-of-concept code from GitHub, ran FOFA queries to find live targets, checked their versions and form endpoints and attempted exploitation itself, and Unit 42's own conclusion is that this confirms a functional, end-to-end autonomous offensive capability. The results argue the other way. Everything the machine tried alone failed, and its own working notes record why each time: Langflow's CVE-2026-33017 at 9.8 needed a public flow identifier and found automatic login disabled, and the n8n pair CVE-2026-21858 at 10.0 and CVE-2025-68613 at 9.9 needed an unauthenticated form accepting file upload and found authentication enabled. Every confirmed compromise in the campaign was manual. Reach was never the constraint: FOFA returned 647,017 n8n instances worldwide and 25,209 inside China, of which the agent sampled roughly 100 and probed about 40 unique addresses, and across more than 460 targeted systems Unit 42 counts three confirmed exploitations, a total the report itself notes does not cleanly reconcile with its instance-level figures. Model selection was deliberate: the operator used Claude Code for connectivity and proxy validation, evaluated Qwen, GLM, Kimi and MiniMax, and ran the campaign on DeepSeek, while OpenAI's safety systems refused the requests that violated its policies and disabled an account linked to the activity.

On the local side the day after a release is a different mode of work. Pull request 7645 routes six explicit Vulkan setup failures in the Studio setup scripts through the failure helpers rather than bare exits.

## Relation to My Own Predictions

The user's first standing prediction (malicious local LLM as malware plus zero-trust as the fundamental safeguard) gets its weaponization leg the most literal instance it has yet had and its safeguard leg a repair that stops one step short of the thesis. The protocol attack surface the thesis also names supplied the day's other half, and there the boundary was simply absent: Ruflo's Model Context Protocol bridge published 233 high-privilege tools on an unauthenticated POST /mcp because the shipped docker-compose bound port 3001 to 0.0.0.0, CVE-2026-59726 scores 10.0, and one request reaches stored conversations, the environment variables holding model API keys, a MongoDB instance running without authentication, agent swarms billed to the victim's own keys, and a learning store whose poisoned entries taint the outputs served to every other user.
