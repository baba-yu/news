### Predictions check

El ciclo de hoy es un día de herramientas abiertas con una columna de seguridad inusualmente firme, y lo llamativo es cómo el stack local-primero y la historia de reforzar-para-producción resultan ser la misma historia contada desde dos lados. La brecha honesta es que ningún motor ha publicado todavía esa política de seguridad con nombre y su proceso de CVE coordinado como criterio declarado que bloquee la publicación.

La mitad de ajuste de ese bucle se cierra con igual fuerza, y ancla su propia predicción fresca. La v0.1.481-beta de Unsloth (7 de julio) deja de ser un mero entrenador: un LoRA para MoE de 3 a 5 veces más rápido mediante detección automática de MoE agrupada y ajuste de primer nivel para DeepSeek-V4-Flash conviven con una exportación de una sola pasada que emite FP8/INT8 portable, FP8/FP4 comprimido y GGUF imatrix sin una etapa de cuantización aparte, y ahora integra un servidor de API local al estilo llama-swap que alterna automáticamente entre los GGUF descargados y los descarga en inactividad para recuperar VRAM. Esa es la evidencia de origen para el nuevo pronóstico **los kits de fine-tuning local absorben la capa de servido por defecto para el H1 2027**, porque funde el ajuste, la cuantización y exportación, y el servido en un único bucle local, erosionando la frontera entre el marco de ajuste y el servidor de inferencia.
