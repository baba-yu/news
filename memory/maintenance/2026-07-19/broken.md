# Maintenance escalations — week ending 2026-07-19

24 `broken` judgements across 18 predictions. These are data or pipeline defects, NOT content staleness — per `design/scheduled/6_weekly_maintenance.md` Step 2 they are escalated for human review and deliberately not auto-fixed. Every one carries `proposed_action: noop`.

## Root causes (most findings are instances of these)

1. **Time-window parser drops or mis-anchors period tokens** (`app/src/timewindow.py`). A trailing quarter/half beats an earlier runway start, so 431 of 809 windowed `needs_tasks` sit exactly on their parent prediction's landing window — the schema explicitly says this column is the runway and NOT the landing destination. Separately, hyphenated quarters (`Q3-2026`) and bare modifier+year (`Mid-to-late 2026`) parse to `(None, None)`; 59 of 114 NULL-window rows carry a human-readable period token the parser drops. Fix belongs in the parser plus a re-derive; rewriting the prose would mask it.

2. **Readings edge extraction has not run since 2026-06-10.** `prediction_chain` last wrote 2026-06-10T10:34:13Z, `prediction_relations` 2026-06-09T18:25:42Z; 230 of 282 predictions have zero edges. Prior runs recorded this as per-prediction `fresh` ("no edges exist; nothing landed upstream"), which converts a pipeline outage into a standing healthy verdict.

3. **The structured layer cannot record contradiction.** All 6,626 `prediction_evidence_links` rows are `support_direction='support'` with `contradiction_score=0.0`; no snapshot has ever been `contradicted`. Multiple bridges this week read as explicit counter-evidence in prose while their links score as support. This also makes Step 0's `new_contradict` selection signal and the spec's flagship Bridge->Reasoning rule unreachable.

4. **`needs_tasks.status` never transitions.** All 923 rows are `'open'`; `'done'` has never been written, so the Bridge->Needs completion path has never fired.

5. **Bridge text attributed to the wrong prediction.** Several `validation_rows` carry a `bridge_text` written about a different prediction, while the same row's `related_items_text` is correctly on-topic. The mismatched text is scored as supporting evidence at relevance 3-4.
