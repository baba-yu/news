- **A ten-page prompt gets GPT-5.6 to close a 1996 optimization gap** — Phillip Kerger posted a proof on July 14 establishing that minimizing a convex Lipschitz function over a d-dimensional Euclidean ball, deterministically and using only exact function values, requires Omega(d^2 / log(d+1)) queries at accuracy Theta(d^-1/2).
