- **GhostApproval symlink redirects an AI coding agent's write onto SSH keys; six vendors split** — Wiz Research publicly disclosed GhostApproval on July 8, a trust-boundary flaw that turns a decades-old filesystem feature — the symbolic link — into a repository-borne attack on AI coding assistants. A malicious repo ships a file with an innocuous name such as project_settings.json that is actually a symlink pointing at ~/.ssh/authorized_keys; when a developer asks the agent to set up the workspace or follow the README and approves what looks like a harmless config edit, the write lands on the SSH file instead, planting an attacker's key and granting passwordless remote access. The core failure is a consent bypass: the approval dialog shows only the benign filename, so the human okays an edit whose real target they never see resolve. Wiz reported it to six vendors — Amazon Q Developer, Anthropic's Claude Code, Augment, Cursor, Google Antigravity, and Windsurf. Amazon (CVE-2026-12958), Cursor (CVE-2026-50549), and Google Antigravity shipped fixes; Augment and Windsurf were still unpatched at disclosure; and Anthropic disputed that Claude Code's behavior is a bug, arguing a developer who trusts a directory and approves an edit owns that decision, placing it outside its threat model. The split verdict is the real story: the industry has not agreed whether silently following a symlink into a sensitive path on the user's behalf is the tool's vulnerability or the user's mistake. [Wiz - GhostApproval: a trust boundary gap in AI coding assistants](https://www.wiz.io/blog/ghostapproval-a-trust-boundary-gap-in-ai-coding-assistants), [The Hacker News - GhostApproval symlink flaws could let malicious repos run code in AI coding agents](https://thehackernews.com/2026/07/ghostapproval-symlink-flaws-could-let.html)

- **ThorArena benchmark exposes humanoids failing under real contact forces** — Researchers at the Technical University of Munich published ThorArena on arXiv, a benchmark that stress-tests humanoid whole-body control under the deliberate, load-bearing physical contact that real human-robot co-working involves — not collision avoidance, but active force exchange. The team captured synchronized whole-body motion and hand forces from human operators wearing VR headsets, motion trackers, and 3D-printed force-sensing tools while performing six contact-rich chores — lifting and lowering a water container, pushing and pulling a chair, and co-carrying an object with a partner — then replayed those forces in simulation against representative control policies. Their metric, the Force-Aware Tracking Score (FATS), jointly grades tracking accuracy, robustness across force levels, control effort, and whether the robot stays upright to the end of the episode. The headline finding: force-informed evaluation exposes large performance gaps that stay invisible under conventional no-force testing, and the authors' own Thor2 policy was the only entry to hold near-perfect balance across all six tasks. The result lands as Figure, Agility, and Boston Dynamics push humanoids from pilots into factories and warehouses, where a person will inevitably lean on, push, or hand something to the robot — precisely the regime today's controllers handle worst.
