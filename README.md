- **A CVSS 10.0 flaw left 233 privileged tools open on Ruflo's MCP bridge** — Noma Labs disclosed CVE-2026-59726, which it named RufRoot, on Wednesday, July 29, with the trade write-ups following on Thursday, July 30; it carries the maximum CVSS score of 10.0. The affected project is Ruflo, an open-source multi-agent orchestration platform that began life as Claude Flow and now serves as a harness for Anthropic's Claude and OpenAI's Codex, with more than 66,500 GitHub stars. The defect sits in its Model Context Protocol bridge, an Express.js server that brokers every tool invocation across agent workflows. That bridge's POST /mcp endpoint had no authentication, and the shipped docker-compose configuration bound port 3001 to 0.0.0.0, so a default self-hosted deployment published 233 high-privilege tools — shell command execution, database operations, agent management and memory storage — to anyone who could reach the port. A single unauthenticated HTTP request invoking the terminal-execution tool runs commands inside the container as the node user; from there an attacker can read stored user conversations, lift the environment variables holding model API keys, reach a MongoDB instance that was running without authentication, spawn agent swarms billed to the victim's own keys, write persistent payloads into the /app directory, and poison the AgentDB learning store so that the outputs served to every other user of that deployment are tainted. Noma's framing is that the bridge is not an auxiliary debug interface but the platform's central nervous system, controlling all tool calls and agent actions. Every release before 3.16.3 is affected; maintainer Reuven Cohen shipped 3.16.3 within 24 hours of the June 30 responsible disclosure, binding the bridge to loopback, requiring a bearer token, gating terminal execution behind explicit opt-in, enabling MongoDB authentication and tightening container and cross-origin controls. The half of the problem that does not patch away is the memory poisoning: Amit Jena, an AI development manager at Kanerika quoted in CSO Online's coverage, argues that adoption of the protocol has outrun the security defaults built into orchestration tooling, and that poisoned agent memory is not a product-specific failure.
