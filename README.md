- **An experiment across more than 40,000 runs measures how well humans approve agent commands, and the answer scales with disguise** — Alex Wauters published an analysis on the Scale X blog on Wednesday, August 5 of an interactive browser game in which the player is the human approver for a coding agent, accepting or denying each command under time pressure. Across more than 40,000 runs and roughly 409,000 approve-or-deny decisions, mean accuracy was 66.3%, and the miss rate tracked how much a hostile command looked like one: 11.7% for obviously destructive commands, 23.8% for persistent mutation attacks, 33.4% for exfiltration and code execution, and 35.0% for scope violations. 35.2% of players caught every threat, but only 20.8% managed that while blocking no more than one in five safe commands; 7% approved everything put in front of them; and 32.9% of sessions ended on a negative score. The single most-missed command was npm run analyze, approved 64.7% of the time even though the malicious payload was visible in the history log. The author is explicit about the artificiality — threats appeared in 34% of commands, far above any real workload, and a timed game is not a working day — and that caveat cuts both ways, because a real operator sees the hostile command far more rarely and is therefore less primed for it. What survives the caveat is the ordering: the further a hostile command sits from the shape people are trained to fear, the more reliably it gets waved through. That is an argument for putting the check in the tool layer, where the payload is inspected, rather than in the approval prompt, where only the command line is.
