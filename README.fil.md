### Predictions check

Ang pinakamakapal na puwersang senyales ay ang pares ng CVSS 9.8 na zero-click sandbox-escape na depekto na inilahad ng Cato AI Labs sa Cursor coding IDE, parehong naayos sa Cursor 3.0: isang path traversal sa pamamagitan ng opsyonal na working_directory parameter at isang symlink-resolution na fallback.
