- **Ginagawang sandata ng GhostApproval ng Wiz ang symlink para ilihis ang file write ng AI coding agent patungo sa SSH keys; nagkahati ang anim na vendor** — Pampublikong inihayag ng Wiz Research ang GhostApproval noong July 8, isang trust-boundary na depekto na ginagawang repository-borne na atake ang isang ilang-dekadang symbolic link laban sa mga AI coding assistant. Naglalaman ang isang malisyosong repo ng file na may inosenteng pangalan tulad ng project_settings.json na sa totoo ay isang symlink na nakaturo sa ~/.ssh/authorized_keys; kapag hiniling ng developer sa agent na i-set up ang workspace at inaprubahan ang mukhang inosenteng config edit, sa halip ay napupunta ang write sa SSH file, na nagtatanim ng key ng umaatake para sa passwordless na remote access. ### Predictions check

Umiikot ang cycle ngayon sa iisang security disclosure na muling nag-aayos sa grupo ng coding-agent: ang July 8 GhostApproval na natuklasan ng Wiz Research. Dito, naglalabas ang isang malisyosong repository ng file na may mukhang-inosenteng pangalan — project_settings.json — na sa totoo ay isang symbolic link patungo sa ~/.ssh/authorized_keys. Kaya ang developer na nag-aaprubahan sa mukhang walang-anumang config edit ay hindi sinasadyang nagtatanim ng key ng attacker at nagbibigay ng passwordless na remote access. Ang pagkabigo ay isang consent bypass: ipinapakita lang ng approval dialog ang inosenteng filename, hindi kailanman ang na-resolve na destinasyon. Iyon ang ebidensya ng pinagmulan ng sariwang forecast ngayon na 'AI coding assistants make symlink-aware write consent the default' (July 12), at ang tugon ng anim na vendor ang hindi maiiwasang salik nito — naglabas ng fix ang Amazon Q Developer (CVE-2026-12958), Cursor (CVE-2026-50549), at Google Antigravity na nireresolba at ipinapakita ang tunay na path, hindi pa na-patch ang Augment at Windsurf noong disclosure, at itinanggi ng Anthropic na bug man lang ang gawi ng Claude Code, na nangangatwirang ang developer na nagtitiwala sa isang directory ang may-ari ng desisyong iyon. Ang hating hatol — kalahati ng larangan na itinuturing na depekto ang tahimik na pagsunod sa symlink habang inilalagay ng isang vendor ito sa labas ng threat model nito — ang tunay na kuwento, at ito mismo ang kawalan ng linaw na inaasahan ng prior na 'agent-sandbox isolation becomes a named procurement requirement' (July 7) na lulutasin ng wika sa panig ng mamimili.

Kumakalat ang GhostApproval sa lahat ng nakatayong security forecast ng linggo, na lahat ay tumuturo sa iisang nawawalang primitive — nasa harness at sa approval gate nito ang matagalang mitigasyon, hindi sa modelo. Pinatitibay nito ang forecast na 'coding agents ship default-deny sandboxes for untrusted-repo audits' (July 11) bilang isa pang untrusted-repository na atake na ginagawang armas ang isang agent habang karaniwang inaayos ang workspace. At ito mismo ang allowlist-at-approval na kontrol na inaasahan ng forecast na 'LLM client libraries ship a permission-gated coding-agent loop' (July 8) na magiging first-class primitive, bagaman ang mga fix ngayon ay inilalabas sa loob ng mga produktong tulad ng Claude Code at Cursor, hindi sa pinangalanang client libraries. Ang parehong-linggong pag-patch ng Amazon at Google sa sarili nilang coding agent ay pumapasok sa prior na 'agent-runtime security folds into a hyperscaler-native defense tier' (July 7), na nagpapatunay na ang mga may-ari ng platform na inaatake ang runtime ang may hawak ng insentibo para akuin ang tugon. Dalawang dormant na longshot ang muling nabubuhay sa parehong senyales: ang longshot na 'Agent-in-the-Loop Secret Exfiltration tops CIS and OWASP risk lists' (April 20), dahil ang GhostApproval ay isang high-profile na agent-mediated na credential-exfiltration na pangyayari sa anim na assistant, at ang longshot na 'coding-agent platform ships trifecta capability gate as default' (June 28), na binabasa ang atake bilang tipikal na lethal-trifecta na kadena ng untrusted na nilalaman, file-write access, at panlabas na komunikasyon. Sa lahat ng mga ito, pangangailangan ang ibinibigay ng araw na ito, hindi paglalabas — tatlong write-path na fix, walang magkakatulad na default, at wala ring attestation log o capability gate.

Ang pagtaas ng Micron noong July 9 ng US commitment nito tungo sa mahigit $250 billion hanggang 2035 — isang $50 billion na pagtaas, kasabay ng pagbuhos ng unang konkreto sa Clay, New York megafab nito nang isang quarter nang mas maaga sa iskedyul at ng inulit na layuning gawin sa loob ng bansa ang 40% ng DRAM nito — ay tahasang binalangkas bilang tugon sa memory sa panahon ng AI. Dumating ito ilang araw matapos ilaan ng record na US listing ng SK Hynix ang mga nalikom para sa EUV na kapasidad, na nagpapatibay sa forecast na 'SK Hynix converts ADR proceeds into booked EUV orders' (July 11) at sa premise ng demand sa likod ng prior na 'SK Hynix sustains triple-digit year-over-year revenue growth' (July 9): naglaan ng bagong kapital ang dalawa sa tatlong malalaking memory maker sa iisang ubos-na-ubos na HBM-at-DRAM na bottleneck sa loob ng isang linggo. Sa riles ng robotics, muling pinapatakbo ng ThorArena benchmark ng Technical University of Munich ang naitalang datos ng galaw at puwersa ng tao para iskorin ang humanoid whole-body control sa ilalim ng tunay na kontak. Natuklasan nitong bumababa nang husto ang mga nangungunang controller kapag pumasok ang load-bearing na puwersa, at tanging ang Thor2 policy ng mga may-akda ang nakapagpanatili ng balanse sa lahat ng anim na chore — ang ebidensya ng pinagmulan ng sariwang forecast ngayon na 'humanoid whole-body control adopts force-aware contact evaluation' (July 12) at katamtamang muling pagbuhay ng longshot na 'captive in-house fleets lead paid humanoid deployment' (June 22), dahil sinusukat nito ang kahandaan sa sahig ng pabrika ng grupong Figure, Agility, at Boston Dynamics. ### Predictions check

Unang gumalaw ang axis ng presyo: dinala ng malawakang paglulunsad ng OpenAI ng GPT-5.6 family noong July 9 ang isang malinaw na tatlong-antas na hagdan — Sol sa $5/$30 kada milyong token, Terra sa $2.50/$15 bilang GPT-5.5-class na performance sa halos kalahati ng gastos, at Luna sa $1/$6 para sa mga high-volume na pipeline — habang binuksan ng Muse Spark 1.1 ng Meta ang una nitong may-presyong external API sa $1.25/$4.25, mas mababa sa bawat kakumpitensyang flagship tier, na may nangungunang mga tool-use na iskor (88.1 MCP Atlas, 54.7 JobBench) at ad-funded na estrukturang kayang ituring na opsyonal ang API margin.
