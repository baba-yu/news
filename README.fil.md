- **Nag-iwan ang isang depektong CVSS 10.0 ng 233 tool na may pribilehiyo na bukas sa MCP bridge ng Ruflo** — Inilahad ng Noma Labs ang CVE-2026-59726, na tinawag nitong RufRoot, noong Miyerkules, July 29, at sumunod ang mga sulatin ng industriya noong Huwebes, July 30; dala nito ang pinakamataas na CVSS score na 10.0. Ang apektadong proyekto ay ang Ruflo, isang open-source na plataporma sa multi-agent orchestration na nagsimula bilang Claude Flow at nagsisilbi ngayong harness para sa Claude ng Anthropic at sa Codex ng OpenAI, na may mahigit 66,500 GitHub star. Nakaupo ang depekto sa Model Context Protocol bridge nito, isang Express.js server na dinadaanan ng bawat pagtawag sa tool sa lahat ng agent workflow. Walang authentication ang POST /mcp endpoint ng bridge na iyon, at itinali ng ipinadalang docker-compose configuration ang port 3001 sa 0.0.0.0. Dahil doon, inilathala ng isang default na self-hosted na deployment ang 233 tool na may mataas na pribilehiyo, kabilang ang pagpapatakbo ng shell command, mga operasyon sa database, pamamahala ng agent at pag-iimbak ng memory, sa sinumang makakaabot sa port. Isang HTTP request lamang na walang authentication na tumatawag sa tool ng terminal execution ang nagpapatakbo ng command sa loob ng container bilang node user. Mula roon, kayang basahin ng umaatake ang nakaimbak na usapan ng mga gumagamit, kunin ang mga environment variable na naglalaman ng model API key, abutin ang isang MongoDB instance na tumatakbo nang walang authentication, magpasibol ng mga kuyog ng agent na sisingilin sa sariling key ng biktima, magsulat ng mga nananatiling payload sa direktoryong /app, at lasunin ang AgentDB learning store upang marumihan ang mga inihahain na output sa bawat isa pang gumagamit ng deployment na iyon. Ganito binalangkas ng Noma: hindi pandagdag na debug interface ang bridge kundi ang sentral na sistema ng nerbiyos ng plataporma, na kumokontrol sa lahat ng tool call at kilos ng agent. Apektado ang bawat release bago ang 3.16.3; naglabas ang tagapangalagang si Reuven Cohen ng 3.16.3 sa loob ng 24 oras mula sa responsableng paglalahad noong June 30, na itinali ang bridge sa loopback, hiningi ang bearer token, inilagay sa likod ng tahasang opt-in ang terminal execution, binuksan ang authentication ng MongoDB at hinigpitan ang mga kontrol sa container at sa cross-origin. Ang kalahati ng suliraning hindi nawawala sa patch ay ang paglason sa memory: iginigiit ni Amit Jena, isang AI development manager sa Kanerika na sinipi sa balita ng CSO Online, na nalampasan na ng paggamit sa protocol ang mga default sa seguridad na nakatanim sa mga kagamitan sa orchestration, at hindi partikular sa isang produkto ang pagkabigong dulot ng nalasong memory ng agent.
